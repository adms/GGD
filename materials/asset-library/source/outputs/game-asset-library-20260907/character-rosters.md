全部 276 筆已補上作品出處，共 131 個作品／題材分組。

對照依據包括角色名、內部代碼、背景、成就、目前立繪和改版公告。資料站背景未必明寫原作名稱，也可能保留改名前的設定；特殊情況見狀態與備註。
本表保留遊戲內簡體原名，別名欄補上原作人物；不含所有跨作品皮膚角色。

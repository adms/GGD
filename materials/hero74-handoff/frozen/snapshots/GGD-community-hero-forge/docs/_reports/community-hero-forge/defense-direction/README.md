# 阿薩謝爾 E：方向條件與巢狀表單

本批在 `e2706f68` 之後的功能分支工作樹實作，尚未發布。範圍是 M07/M10 的方向判定與可調整表單；近身技能分類及影子演出仍待完成，不能將本批視為 M07 或阿薩謝爾原設計整體通過。

## 行為與設定

- 通用 `facing` 條件以命中當下的主體朝向、雙方中心計算；`subject` 可選自己／目標，`arcDegrees` 為完整角度，界限 1–360°，含扇形邊界。不同區、缺少位置、重疊中心或零朝向不算有可判定方向。
- 阿薩謝爾 E 使用正面 120°（左右各 60°）、距離 ≤2.5、0.5 秒窗口。合法敵方普攻觸發一次免傷與對原攻擊者反擊後卸除窗口。角度和距離可透過產品內的條件選單微調。
- 效果與觸發器內的 shared condition 現在也使用條件編輯器；既有未能表達的深層條件保持明確唯讀，畸形輸入保持可修復原值，不會靜默清掉條件。
- 原始名稱／sourceDesign 保留。R→EX 仍只消耗自己的 R 詛咒，消耗三層資源並給敵方 AD/AP +10%，不施加通常 EX 傷害。

- 首輪兩個邊界用例失敗：第三位測試角色與防守者身體重疊，移動系統先把防守者由 x=-40 擠至 -40.168，改變實際距離及入射角。`boundary-diagnostic.log` 保留前後位置；將無關隊友移開後用完整 world.step 重測通過，沒有放寬實際判定。

- 首次 UI 腳本錯將 DOM 節點作為可序列化回傳值；其後兩次遇到重载時機與熱更新清空 DOM。三份失敗收據保留；停止產生器、等待頁面載入事件及實際控制項後重測成功。這些失敗不被算作產品通過證據。

# Infinity Strash 巴恩變身後來源鑑別 v2

這條流程讀取使用者已保存的兩個 Windows Steam 主 PAK 及其完整索引。它會重新驗證兩個 PAK 的大小與 SHA-256，重算既有 EN801／EN653 解包檔，並從原始 PAK 抽出 EN801、EN653、EN680、EN681 的身體與角色藍圖探針，逐檔記錄大小與 SHA-256。

身份界線固定如下：

- EN801：巴恩大魔王，現有身體經視覺驗收確認為老年／變身前。
- EN653：密斯特巴恩，獨立角色。
- EN680：巴蘭，獨立角色。
- EN681：龍魔人巴蘭／巴蘭形態，仍屬巴蘭。

若完整索引只有 EN801/00 身體，且沒有帶明確 young／true／final／post／transform 等身份詞的 Vearn 路徑，結果維持「變身後年輕真身未找到」。數字相近、密斯特巴恩、巴蘭或 Kaizer Phoenix 輔助骨架都不能填補這個缺口。

本流程不從網路抓取、不繞過登入或付費，也不把索引稽核宣稱成模型轉換、後台選項或正式部署。

## §1 三軸怎麼量（Codex 可以照著自檢）

每一軸都輸出一個**計數**，⛔ 不是分數。計數不相加成一個判決 ——
它們只被拿來**排序**（差最多的排前面）。誰重要是 owner 的決定。

⭐ 動畫軸有**兩個讀法**：拍數（時間上分得開的節拍）與**移動中的模型**
（原作把一具 locust dummy 沿路徑推出去）。⛔ 兩者不可互相取代 ——
一支「不等待、只把模型推過去」的技能拍數是 0，而它的演出整段都在移動上。

| 軸 | 原作那一側怎麼數 | GGD 那一側怎麼數 | 缺口 |
|---|---|---|---|
| **特效正確性** | 作者**指名過**的模型 stem：`realArt[]` 裡 provenance ∈ `{jass-literal, w3a-override, w3h-override}` 的，∪ JASS 演出鏈裡 `AddSpecialEffect*` 逐字打出來的路徑。⛔ `stock-inherited` 不算 —— provenance 合約自己寫著它「NOT intent」 | `vfxKey` 反推：`fx.w3x.<類>.<stem>` 才對得上一份原作模型；`fx.prim.*` 是**通用原型**，一份都對不上。⭐ **∪ `spawnModelFx.modelKey`** —— 移動中的那具模型也是播出來的原作美術，stem 從模型文件的 `glbPath` 檔名推導 | 指名過但播不出來的 stem 數 |
| **動畫正確性** | 演出鏈裡 `TriggerSleepAction`/`PolledWait` 的**拍數**，且**展開字面上界的 `loop`**（七連斬寫成 `exitwhen i > 7`，不展開只有 2 拍） | 時間上分得開的節拍：`dot` 的 tick 數（`durationSec/intervalSec`）＋ `delayed` 節點＋模板中**未被宣告失效**且 `unit == "count"` 的分段參數 | `max(0, JASS 拍 − GGD 拍)` |
| **動畫正確性②：移動中的模型** | 演出鏈裡 `SetUnitPosition`/`SetUnitX`/`SetUnitY` 的呼叫次數（展開 `loop`）—— 那是 locust dummy 被一格一格推出去的痕跡。⚠️ **>1 次才算一段路徑**，一次是瞬移／擊退的落點修正 | `spawnModelFx` 的**段數** ＝ 實例數（`radial`/`orbit` 讀 `count`，直線恆為 1）× 沿路取樣數（`onTouch` 才有，公式與 `sim/effects/spawnModelFx.ts` 同一條） | 原作推了模型而 GGD 一具都沒有 → 1，否則 0。⚠️ 它是**機制的有無**，⛔ 不是段數差 —— 段數跟著 tick 率飄 |
| **傷害正確性** | 演出鏈裡 `UnitDamage*` 的呼叫次數（同樣展開 `loop`） | 扣血葉數：`kind` 以 `damage` 開頭、或帶 `damageType` 的節點；`dot` 按 tick 展開。⭐ `spawnModelFx` 的 `onTouch`/`onArrive` 底下的葉子要**乘上實例數** —— 12 具各掃一次就是 12 次，⛔ 不是 1 次 | `max(卡面承諾 − GGD, JASS − GGD, 0)` |

### ⚠️ 三條這把尺自己要遵守的規矩

1. **演出鏈是跟著 `EnableTrigger` 走的，⛔ 不是「同名的那個函式」。**
   WC3 的時序演出幾乎不寫在同一個 trigger 裡：施法那一個 `EnableTrigger` 下一個。
   只用 rawcode 接合會整段漏掉 —— 42-04 的 rawcode 只掛在 `The_End_ofWorldStart`，
   而它承諾的連續打擊住在它啟動的 `The_End_ofWorldCasting`（0.1 秒週期 timer）裡。
2. ⭐ **讀說明找機制之前先剝掉整段 `「…」`**（owner 2026-08-12：那是**角色對白**，
   不是真正的效果）。含跨行、含行中。量到過的誤報：一句台詞裡的「在35秒後」
   會讓一支技能被判成有 35 秒延遲時序。
3. **模板自己宣告的 `inert` 是證據，不是藉口。** 一個標了 `inert` 的參數
   （例：分段時序未支援）等於作者已經承認這一段演不出來 —— 它會被列進缺口表的
   `inertParams`，⛔ 不會因為「已宣告」就從缺口裡消失。

## §2 詞彙（從出貨內容推導，⛔ 不是手寫的清單）

| 家族 | 意思 | 支數 |
|---|---|---:|
| w3x | `fx.w3x.*` —— 從原作模型抽出來的粒子層，**對得上** stem | 24 |
| prim | `fx.prim.*` —— 通用原型（火/冰/聖/虛空…），⛔ 對不上任何原作 stem | 342 |
| other | 既不是 `fx.w3x.` 也不是 `fx.prim.` 的自訂 id | 18 |
| none | ⛔ 沒有 `vfxKey` | 36 |

## §5 通過的樣子（⭐ 兩份都是出貨內容，⛔ 不是編的範例）

### §5.2 特效軸滿分（`vfxKey` 真的對得上原作 stem）

符合的有 **7** 支。⚠️ 用了 `fx.w3x.*` 的一共 24 支 ——
差額是「播了一份原作模型，但作者**還指名過別的**」的那些。

⭐ **12-04 龍氣爆發**　`godie-e007.r`　·　`vfxKey` = `fx.w3x.particle.supershinythingy.p00`

形狀是 `fx.w3x.<類>.<模型 stem>.<粒子層>` —— 中間那一段就是 w3a/JASS 裡
逐字打出來的模型檔名（去目錄、去副檔名、轉小寫）。⭐ **接合鍵在檔名上**，
⛔ 不在技能名上：改技能名不會弄壞它，改 stem 會。

```json
{
  "effects": [
    {
      "kind": "damage",
      "damageType": "magic",
      "amount": {
        "damageTier": "大",
        "ratios": [
          {
            "stat": "ap",
            "coeff": 1.3
          }
        ]
      }
    }
  ],
  "vfxKey": "fx.w3x.particle.supershinythingy.p00"
}
```

### 收下這份合約的人要做的三件事

1. **特效**：能對上原作 stem 就用 `fx.w3x.<類>.<stem>`；真的沒有那份模型時才退
   `fx.prim.*`，⛔ 而且要知道那一支在特效軸上會一直記著缺口。
2. **動畫**：卡面說「連斬七次」，`effects` 裡就要有七個**時間上分得開**的節拍
   （`dot` 的 `durationSec/intervalSec` 或 `delayed` 串接），⛔ 不是一次結算。
3. **傷害**：扣血葉數要對得上承諾。⭐ 第一·五守則 —— 卡片上不可以有
   「說了但不會發生」的字；做不到就**改描述**，⛔ 不是留著一句謊話。

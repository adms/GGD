## 「再發生」的是什麼

2026-08-13，owner 給了一條裁決：

> 「70-002 樹海降臨 …[千年練成] 追加 500% [AP]傷害，並且**[回復][周圍]自己與友方隊伍生命10%**」

而我把它套到了 **70-00 紮根的芬多精光環**（+5% 生命回復，一個 w3x 時代的遺留），
因為我去讀了那支技能 JSON 裡**舊的** description。owner 的回覆是：

> 「**你不是有做一個最新版本的英雄的技能列表及說明(JSON & MD)? 怎麼會搞混呢?**」

⭐ **這句話是對的，而且它指出的不是我不小心，是一個結構問題**：
新規格與舊規格**住在同一層目錄裡**，兩份都長得像權威文件。
第〇·六守則的階梯（新版說明 > 編輯器 JSON > JASS > w3x 說明 > w3x 設定）
只在**我記得去查階梯**的時候有用 —— 而出事的當下沒有人在讀散文。

**所以這個資料夾是把那條階梯變成一個目錄結構。**

---

## 規則（三句）

1. **第 3–5 層（JASS / w3x 說明 / w3x 設定）的衍生文件，一律住這裡。**
   它們是**考古**，不是規格。⛔ 不可以出現在 `docs/` 第一層 ——
   那一層放的是「現在成立的東西」。
2. **90 支重製技能的規格只有一個出處**：`tools/skill-remake/batch1.py` 的那張表。
   它產出 `docs/英雄技能第一批重製-90支.md`（owner 規格 ↔ JSON 並排）與
   `docs/技能編輯器引擎須知 20260811.md` §13.10。⛔ 兩份都不可以手改。
3. **這裡的東西不刪。** 被取代的原作數值要留著 —— 第〇·六守則逐字：
   「⭐『分開』不是『丟掉』…測試可以跟著設計走，**知識不可以無聲消失**」。

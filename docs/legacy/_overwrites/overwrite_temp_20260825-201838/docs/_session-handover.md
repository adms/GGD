## 五、技能連動的可行性（12-agent 查證的結論）

owner 問「某狀態／某標記／某變身下，其他技能加效果、加機制、縮冷卻」。一句話：

> **你可以「加」，不能「乘」。**

兩條真的通路（`applyBuff.hooks` + `abilitySlot`；`damage.comboBonus`）都是**附加
一件事**，沒有任何一條能乘上另一支技能自己的數字。
⚠️ 而且附加上去的效果**永遠以 rank 1 執行**（`hooks.ts` 寫死），所以要隨等級成長
得靠 `ratios` 不能用 `perRank`。

寫得出來：變身期間的被動／變身期間 Q 多一段爆炸／Q 命中後 W 多做一件事／
自己身上有標記時這一發 +X／某條件下普攻附帶減速／全部技能冷卻縮減。

寫不出來：**縮短特定技能的冷卻**（→ #284）· 敵人身上有某狀態時 · 疊 N 層後引爆 ·
層數餵進傷害 · 貼在敵人身上的標記（客戶端零讀取端）· 變身期間多一格技能。

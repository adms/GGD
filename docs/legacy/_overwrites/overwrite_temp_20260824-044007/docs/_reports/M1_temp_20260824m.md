**⚠️ 三個刻意的決定：**

1. **必須先 `registerAll`** —— 磁碟上的 `effects: []` 是**模板慣用法**（出貨樹 69 支如此）。
   掃磁碟 JSON 會得到 69 個幽靈空技能（失敗形態⑤）。
2. **`onTemplateFailure` 用出貨預設 `"degrade"`** —— 這樣「模板展開失敗」也會走到這條閘
   被逐字指名，⛔ 而不是換成另一種訊息的例外。
3. **豁免是推導的，⛔ 不是手寫清單** —— 只收領頭標籤 `主動*` 的。
   `[被動]`/`[靈氣]`（`effects` 空是**正確**慣用法）、`[輔助]`（83 支，出貨內容裡有兩個讀法 ⇒ 收了就是誤報）、`[切換]`（載體是 `toggle.whileOn`）**天然不收**。
   真的要暫時放行 ⇒ 先開 issue，再寫進 `KNOWN`（要帶票號）。**今天 `KNOWN` 是空的。**

## 1. 公式

```
coeff = BASE × 冷卻 × 吟唱 × 距離 × 目標形狀 × 條件
BASE = 0.602   ← 校準點：一般 R 大招（60s · 吟唱1s · 距8 · 範圍8 · 無條件）⇒ 1.00
```

| 維度 | 乘數 |
|---|---|
| 冷卻 | `clamp(CD秒 / 30, 0.15, 3.0)` 線性 |
| 吟唱 | `1 + 0.5 × min(t, 1.0)` |
| 距離 | `(6 / 半徑)^0.35` |
| 目標形狀 | 單體 2.5× · 直線 1.5× · 範圍 `(3/半徑)^0.5` |
| 條件 | 極小1.0 / 小1.3 / 中1.6 / 大2.2 / 極大3.0 |

## 2. 三把梯子退場
普攻＝冷卻 0.6 秒（乘數 0.15 下限）· 技能＝條件極小 · 特殊條件＝條件大/極大。

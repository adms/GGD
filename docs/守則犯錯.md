⭐ **兩欄是重點**，⛔ 不是「記一句話」：
**守則代號**（犯的是哪一條 → 頻率）＋ **成因代號**（**為什麼**會犯 → ⭐ 改進的抓手）。

**記一筆（⛔ 不要手改這個檔）：**

```bash
bash scripts/rule-slip.sh 技術-離開碼 疲勞重複 "又用 | head 讀 tsc 的離開碼"
```

`--check` 是閘（統計區過期或代號打錯 ⇒ 非零）；`--stats` 只重算統計區。

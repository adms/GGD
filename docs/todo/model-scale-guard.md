# Champion model FULL-BBOX guard (stray effect-mesh tripwire)

The #1 scale audit (`models.md` mdl-02..mdl-05) normalizes and asserts each
champion's **body** height (the largest-vertex mesh, always ≈1.70u). That guard
is blind to a stray effect/particle geoset baked into a `.glb` as solid geometry
— which is exactly how 高町奈葉 (`imported.niya`, godie-o01z / godie-o02v) shipped
as a giant with a 14.5u (8.5×) invisible team-glow beam: the importer's
max-vertex "body" heuristic picked a 745-vert cape geoset as the height
reference, so the whole character was normalized to ~10u tall.

This guard closes that gap at two levels:

1. **Root cause — importer guard** (`tools/w3x-import/w3xlib/gltf.py`,
   `classify_geosets`): recognizes particle/emitter geosets (team-glow
   billboards, additive glow quads with no opaque base) and, when they clearly
   leave the body (tower above / beam past / float above / ring far outside the
   footprint), DROPS them from the baked mesh — they belong in the VFX channel.
   Body height is measured from the **union of the kept body geosets**, so the
   biggest geoset can never be mistaken for the body again. Conservative:
   in-silhouette glows (energy blades, eye glows, a fire ring at body height)
   and all opaque / team-colour body parts are kept. Unit-tested in
   `tools/w3x-import/test/fixture_checks.py` (`w3x-effect-geoset-guard`, see
   `w3x-import.md` w3x-18). Re-running `import_w3x.py` now excludes these geosets
   automatically; the shipped glbs were fixed without a full re-import (niya
   re-baked via `rebake_stripped.py`, the other six surgically stripped via
   `strip_effect_meshes.mjs`).

2. **Regression tripwire — validation guard**
   (`packages/shared/src/content/modelBbox.test.ts`): the TRUE full-bbox height
   of every active champion model is precomputed once (Babylon NullEngine — the
   client's load path) into `modelBbox.fixture.json` and multiplied by the LIVE
   `content/models/*.json` scale, so a future stray mesh — or a hand-edited
   scale — fails the suite loudly. `renderedFull = fullHeight × doc.scale`.
   Caps: **standardCap 2.5u** for a normal champion (hats/weapons included),
   **hardCeiling 3.5u** for everything. A small documented allowlist
   (`imported.heropika` ears, `imported.linkstik` cap — both OPAQUE body
   geometry) may exceed the standard cap but never the hard ceiling.
   `imported.bulbasaur` LEFT the allowlist in #32: its shipped glb predated the
   union-basis normalization, so only the 387-vert trunk geoset was normalized
   and the leaves above it pushed the true silhouette to 3.13u (1.84×). The
   re-bake (`rebake_stripped.py bulbasaur`) normalizes the kept-geoset union, so
   the whole character now renders at 1.70u with no allowlist entry needed.

Fixture regenerated by `tools/w3x-import/gen_modelbbox_fixture.py` from
`MESH_AUDIT.json`. If a champion's scale changes, regenerate the fixture.

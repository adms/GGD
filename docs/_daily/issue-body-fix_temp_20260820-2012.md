⭐ 為什麼要做這件事：`gh issue view N` **只印 body，留言要 `--comments`**。
兩張票的更正（LV30 錨點、不含 HP 系統倍率、回魔三動作）全部只活在**留言**裡，
而 body 最上面仍寫著被推翻的 `Lv18 中位有效血量 9,048` / `refillSeconds ≤15 秒`。
⇒ 下一輪 agent 讀到的是**錯的那一份**，而那正是「為何每次都拿到錯誤的資訊」的機制。

從 v0.22.x 起 `scripts/ruling.sh` 會自動做這件事（閘 C）；**這兩張是它上線前留下的存量**。

貼法（⛔ **前置**到 body 最上面，⛔ 不要刪掉原文 —— 第一·五守則：另存／保留，不是壓縮取代）：

```bash
gh issue view 447 --json body --jq '.body' > /private/tmp/447-old.md
{ cat <本檔 #447 那一塊>; printf '\n---\n\n'; cat /private/tmp/447-old.md; } > /private/tmp/447-new.md
gh issue edit 447 --body-file /private/tmp/447-new.md
```

# 鑄技工坊／VFX Forge 現有技能驗收清單

狀態：候選基準版  
範圍：42 個技能主題、46 份實際技能 JSON  
目的：驗收 Editor 是否能用現有積木從空白重建技能，不代表允許直接套用或 Promote 至遊戲正式內容。

## 一、共同驗收規則

每一份技能都必須完成：

1. 從空白畫布重建，不可只載入既有 JSON 冒充完成。
2. 可以儲存、關閉重開、再次編輯、單檔匯出及 ZIP 匯出。
3. 編輯前後 JSON 必須通過 schema、template、effect graph 與 runtime 驗證。
4. 傷害、耗魔、冷卻、施法距離、有效範圍、吟唱、位移、擊退、移速等適用軸，必須支援「極小／小／中／大／極大」五級距；禁止出現「超大」。
5. Editor 必須顯示經主程式限制器處理後的「實際生效值」，不能只顯示 schema 或作者輸入值。
6. 主動技能至少要有合理施展動作；每個傷害點、位移點與間隔點應對齊角色動作。
7. 被動技能依情境使用普攻、暴擊、格擋、迴避、受擊、觸發或狀態特效，不得播放假的主動施法動作。
8. 一般單次攻擊原則上使用一次清楚、有力量感的主斬擊特效，不得無理由堆疊大量月牙。
9. 快速多段技能才允許使用多個高速斬擊特效，而且每段仍須對應動作或明確表達快到不可見。
10. 貼圖、魔法陣、粒子與模型材質不得出現未去背方板；必須依「貼圖 × blendMode」組合檢查。
11. 有 VFX Script 時必須遵守取代規則，不能與預設綁定疊播兩份。
12. 八招 VFX 能力樣本與本清單產物只能送人工批核，永遠不得直接 Promote。
13. 鏡像技能必須逐欄比較；任一版本修改時，Editor 必須顯示鏡像差異。
14. 驗收結果必須留下 JSON receipt、連續擷圖、失敗原因與對應技能 ID。

## 4. 去重（票逐字：「掉落／領取／**重抽**／復活皆有服務端去重」）

走**同一本**一次性帳本 `Round11Claims`，kind `"reroll"`、key ＝ **王的實體 id**：

```ts
if (!this.round11Claims.claim("reroll", String(bossId))) return;
```

⇒ 斷線重連／重複請求／同 tick 多來源致命讓 `mobBossSlain` 重覆抵達時，
第二次以後 `claim()` 回 `false`。offer 的 key 本身（`r11reroll:<bossId>:<seatId>`）
也是冪等的，⭐ 兩層，⛔ 不是「應該不會重覆」。

⭐ 另外兩道刻意的守門：
* ⛔ **換邊之後的座位不發**（`round11Possessions.has(seatId)`）—— 牠現在是一具王、
  分數已凍結（GH#922），發一件英雄裝備既沒有人拿得到，還會動到王的屬性
* ⭐ 池子抽不出東西 ⇒ **`console.warn` 出聲**再 return，⛔ 不是發一張空卡
  （fail-open 沒錯，**靜默**才是缺陷）

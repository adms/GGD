## ⭐ 最重要的一個發現：architecture gate vs 柵欄的結構衝突，用 seam 化解

`architecture.test.ts`（柵欄外，⛔ 不可動）規定**只有 `render/*` 與 `vfx/*` 可以
import `@babylonjs`** —— 而柵欄只給我 `src/review/**`。解法：`review/**` **一行
@babylonjs import 都沒有**，Babylon 全部透過既有出口操作 ——
`startCastPillarAudition()` 暴露的 `scene`（真 engine、競技場視角、暗地板）、
出貨 `toParticleSystem`、出貨 `AssetManager`；改 material/相機/節點只做**就地
mutate**（不 new）。閘照舊綠，而且正好就是「⛔ 不要自己抄一份參數翻譯」的形狀。

### ⭐ 一條 lane 的工作方式（照這個就不會互相卡）

```
一條 lane 一個 git worktree（isolation: worktree）
  ① 開工前：bash scripts/genguard.sh <你要改的檔>      ← 確認不是產物
  ② 只改柵欄內的檔
  ③ 測試：只跑自己那幾支單檔（npx vitest run <檔>），⛔ 不跑全套、⛔ 不跑 skills:sync
  ④ commit：git commit -F msg.txt -- <逐檔列名>        ← ⛔ 不要 git add -A、⛔ 不要 --amend
  ⑤ 收工：把「要重產的產物」「要加的後台那一行」寫進交接欄
最後：主線收齊 → 一次 skills:sync → 一次 BMPNDD → 出貨
```

並行度上限 `min(16, CPU−2)`；一條 lane 超過 5 分鐘沒新輸出就去看它是不是掛了。

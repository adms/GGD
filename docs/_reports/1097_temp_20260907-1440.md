## ② 改了什麼（三個檔）

### 1. `scripts/product-quarantine.sh` —— 第四個消費端跟上 GH#1096

- `sys.path` 掛上 `tools/parallel-gates`，`from marker_regions import partial_regions`
  —— ⭐ 讀**同一支**判準，⛔ 不抄 marker regex、⛔ 不寫「哪些檔不鎖」的名單。
  讀不到 ⇒ **fail-closed 而且大聲**（整份鎖起來 ＋ stderr 指名），⛔ 不靜默退回舊行為。
- 新增 `is_partial(f)`（含 memo）與 `should_lock(f) = has_author(f) and not is_partial(f)`。
  ⭐ 「該不該鎖」從**一個名詞**變成**兩個名詞的關係**。
- `lock` / `status` / `stuck` 三處改用 `should_lock`；輸出多一格
  `部分產物 N 份不上鎖(GH#1097)`。
- ⚠️ 取捨寫在函式的 docstring 裡：放行之後那幾段產生區段只剩 hook 一層防護
  （檔案 API 直寫攔不到）—— 緩解是 `pnpm docs:readme --check` 逐位元組比對，
  它本來就是 `skills:check` 的一員。

### 2. `tools/parallel-gates/normalizers.json` —— `board:build` 的逐檔範圍

新增一格，`only: ["docs/legacy/_overwrites/_ledger.tsv"]`，理由 624 字（逐行讀過
`gen_board.py::_preserve_previous()`，附**可被反駁的條件**：若哪天它改成產生／擁有那本帳，
這一列就要刪）。⭐ `only` 讓 `docs/_release/ggd-board.html` 照舊是它的產物、照舊鎖。
⇒ 一格落地，**四個消費端**（genguard.sh · hook · quarantine · reconcile.mjs）一起對。

### 3. `scripts/preserve.sh` —— 自解鎖 ＋ fail-loud

- 抽出 `note()`：①先 `chmod u+w`（與 `ledger_table.py::_unlock()` 逐字同一個模式）
  ②仍然失敗 ⇒ **印出真正的錯誤字串**並累計 `LOST`。
- 結尾那一行不再無條件印 `✓`：掉了紀錄就印
  `⚠️ 留底 N 份 …⛔ 而 **L 筆沒記進帳本**（副本在，紀錄不在）`。
- **副本**那一半失敗（`cp -p`）⇒ 大聲 ＋ `exit 1`（`bmpndd.sh` 讀這支的離開碼決定要不要往下走）；
  **帳本**那一半失敗 ⇒ 出聲但 `exit 0`（副本已經在磁碟上了，fail-open 沒錯、靜默才是缺陷）。
- 新增 `GGD_PRESERVE_LOG`（**測試接縫**，與 `GGD_QUARANTINE_IO` 同一個形狀）。

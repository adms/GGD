## 3. 落地了什麼

### `content/abilities/godie-hart.r.json`（唯一真的翻譯）

```json
{ "kind": "spawnVfx", "vfxId": "godie-herocloudkfksword-p0", "at": "bone", "attach": "weapon" }
```

逐字對 JASS `:33877` `AddSpecialEffectTargetUnitBJ("weapon", udg_FF7_CloudUnit, "HeroCloudKFKSword.mdx")`
—— 施法者 ✓ · weapon ✓ · 落在 `comboStrikes.finisher`（該行住在
`Trig_SuperFF7_Func023Func041C()` 的收尾分支）✓。

⭐ **為什麼挑 `godie-herocloudkfksword-p0` 而不是 `fx.w3x.orb.herocloudkfksword.p00`**：
兩份逐欄相同，只差後者帶 `ambient: true`，而 `ambient:true` 會讓 `isSwingTrailDoc()`
把它認成**刀光**（揮劍才噴）。這裡要的是收尾那一擊的**一次性**掛件。
（同一條理由 GH#546 在 `ambient-vfx.json` 的 herosaber 那一列已經寫過。）

⚠️ `godie-hart` **不在 `CHAMPION_FORM_PAIRS`** ⇒ ⛔ 沒有變身對子要一起動。

### 守衛 `packages/shared/src/content/laneWBoneAttachRefsResolve.test.ts`

三條，關掉的是我這一次**親手撞到**的兩個洞 ＋ 一個空集合洞：

1. `vfxId` 是 **soft ref** ⇒ 打錯字：內容驗證綠、`content:build` 綠、`at`⇔`attach` refine 綠、**零像素**。
2. ⛔ 不可以指到 `attachment@1`（票文正是要人拿 mesh 去餵粒子通道）。
3. ⭐ **至少一支引用**（⛔ 空集合不算過）—— 落地前的出貨狀態就是「機制在、引用 0」，
   而掃描式守衛對空集合**永遠是綠的**。⛔ 沒有這一條，它會在最該紅的那天沉默。

**突變**（`Edit` 改回，⛔ 非 git checkout）：把 `vfxId` 換成真的存在的 `attach.godie-e00x.awing`
（`attachment@1`）⇒ ②紅，訊息指名 `godie-hart.r → attach.godie-e00x.awing (attachment@1)`。已還原，`git diff` 只剩 6 行新增。

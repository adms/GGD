## 3.【A】逐支清單

### 3.1 欄位說明

| 欄 | 意思 |
|---|---|
| **階** | L4 原作 emitter 在播 / L3 家族替身 / L2 通用原型 / L1 完全沒有 |
| **來源階** | 四階覆蓋順序：1 作者寫的 `vfxLayers` · 2 作者挑的原作 `vfxKey` · 3 綁定表 · 4 通用原型/空 |
| **原作對應** | ⭐＝真的在播原作 emitter；家＝沿用原作模型身分的家族替身；通＝通用原型；—＝沒有 |
| **音** | ✅ 自己的 `sfxKey`／家＝家族推導／⛔ 沒有 |
| **模** | `spawnModelFx` / `modelKey`（3D 模型特效） |
| **拖** | 綁到的 vfx 文件帶 `stretched`（拖曳尾巴） |
| **緞** | 綁到 `ribbon@1`（緞帶）—— **全 421 支都是空的** |
| **綁點** | `attachTo` / 綁到的文件帶 `anchorBone`（球體綁定位置） |

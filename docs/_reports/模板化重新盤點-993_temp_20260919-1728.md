### 提案 C —— `damage`（12 支）：⭐ 9 支被**一條比錯的規則**擋著，⛔ 不是缺參數

**量到的**：dry-run 裡「`targetsEnemies` 文件 null ≠ 這一族發的 true」出現 **9 次**
（⭐ 全 dry-run **重複次數最高的單一擋點**），全部是 community-review。
出處：`tools/skill-remake/templatize.py:293-295`（`_common_reject()`）：

```python
have = doc.get("targetsEnemies")
if emits_targets is not None and have is not emits_targets:
    return f"targetsEnemies 文件 {json.dumps(have)} ≠ 這一族發的 {json.dumps(emits_targets)}"
```

⛔⛔ **而 `targetsEnemies` 的出貨語意是「省略 ＝ `true`」** ——
`packages/shared/src/content/schema/ability.ts:911-926` 逐字寫著：

> ⭐⭐ **省略 ＝ `true`**（⛔ 不是 `false`、⛔ 也不是「沒有意見」）—— 出貨的判準逐字是 `targetsEnemies !== false`
> …⭐ 比對這個欄位時要**先套預設再比**，⛔ 不要比 JSON 的字面值。

⭐ **而那一行的存在理由，就是同一個錯**：它接著記錄 GH#1245 ——
「同一支技能的兩個載體，一邊寫 `true`、一邊留空 ⇒ 逐位元組比對報成『分歧』，
⭐ 而它們的**行為逐位元相同** ⇒ 一個假的缺陷」。

⇒ ⭐ **`templatize.py` 今天正在犯那條規則點名的錯，而代價是 9 支技能轉不了。**

**⇒ 提案 C-1（一行，最便宜的一筆）**：`_common_reject()` 比對前先套預設 ——
`have = doc.get("targetsEnemies", True) if emits_targets is True else doc.get("targetsEnemies")`
（或更直接：`(have is None and emits_targets is True)` 視為相等）。
⛔ **不要**改成無條件放行 —— 文件明寫 `false` 而家族發 `true` 仍然必須擋。
⇒ 解鎖 **9 支**（`damage` 形狀 **7** 支：community-review-04/06/11/13/28/31/32；
`applyStatus + damage` 形狀 **2** 支：community-review-23/27）。

⭐ **`damage` 這 12 支剛好拆成三堆**：7 支（本提案）＋ 3 支（C-2 的 ground 無 radius）
＋ 2 支（`godie-e007.e` / `godie-o00x.e`，卡在**變身對子**閘：另一半沒一起轉 ⇒ `abilityCodeParity` 會紅）。

**⇒ 提案 C-2（剩下 3 支，⭐ 這一筆我建議先當成內容問題問清楚，⛔ 不要急著做模板）**

⚠️ ⭐ **但在補模板之前要先問**：一支 ground 定位、卻只有單體 `damage` 節點的技能，

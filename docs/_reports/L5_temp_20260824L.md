# L5 — JASS trigger→技能 join 推導表（GH#649 類①，442 列）

日期：2026-08-24 · lane L5 · 柵欄：`tools/w3x-import/join/**`（新）+ `docs/_reports/`
⭐ **這一輪只產推導表，⛔ 沒有動任何 content**（批 2 才套用）。

## 做了什麼

`DUMMY_ORB_MAP.json` 的 823 列 dummy/球體證據裡，**442 列 JASS 沒寫技能 rawcode**——
因為 `GetSpellAbilityId()` 的比較不在同一個 trigger family 裡（spawn 住在被
`EnableTrigger` / `TriggerExecute` / `TriggerRegister*` / timer 轉發啟動的**次級 trigger** 裡，
377/442；或住在共用 helper / 地圖初始化函式裡，65/442）。

新工具 `tools/w3x-import/join/derive_join.py` 從 spawn 那一列往上走呼叫鏈：

```
spawn 列 → 所在函式 → 呼叫者（call / function 引用 / ExecuteFunc("…")）
        → trigger 啟動邊（EnableTrigger/TriggerExecute/TriggerRegister*(gg_trg_X)）
        → timer 轉發邊（TimerStart(udg_T) ↔ TriggerRegisterTimerExpireEvent(gg_trg_X, udg_T)）
        → 直到某個 family 帶技能證據：GetSpellAbilityId=='X'（強）> GetLearnedSkillBJ（強）
          > GetUnitAbilityLevel*（弱）> UnitAdd/RemoveAbility（最弱）
```

BFS 深度上限 8、呼叫者 >20 的 hub 函式不展開（記名）。最近的強證據優先（同支路不再往上）。
rawcode 一律過 `OBJECTS.json` abilities 白名單（擋掉 unit/item/buff 碼）。

## 結果：442 列全數分級

| 信心 | 列數 | 定義 |
|---|---:|---|
| **high** | **102** | 直接呼叫：唯一 caster、1 hop、`GetSpellAbilityId` 強證據（實際全是 depth 1 spell-cast） |
| **medium** | **118** | 經共用函式／啟動邊／timer 鏈（spell-cast 77 · add-remove 22 · level-check 19；深度最深 3） |
| **ambiguous** | **46** | 走得到 ≥2 個候選 rawcode——**候選全列出**（含各自證據與深度），沒有替 owner 挑 |
| **unresolved** | **176** | 推不出，原因逐列記錄（見下） |

⇒ **推出 220/442（49.8%），78 支相異技能**；其中 65 列落在 `ABILITY_GAP.json`
的 178 支占位技能帳本上（`gap_id` 直接可用）。6 列 ambiguous 靠
hero-unit-type（`GetUnitTypeId=='E002'` ↔ gap champion `godie-e002`）成功 tie-break 成 medium。

## 推不出的共同原因（176 列）

| 原因 | 列數 | 說明 |
|---|---:|---|
| **item-driven** | 69 | 鏈上只有 `GetItemTypeId`/`UnitHasItemOfTypeBJ`——是**法器**不是技能；item rawcode 已逐列記在 reason 裡 |
| **map-init 裝飾** | 62 | `CreateBuildingsForPlayer*` / `CreateNeutralPassiveBuildings` 等地圖開場擺設，本來就不屬於任何技能 |
| **trigger 無技能證據** | 25 | 走到 root trigger 但整條鏈沒有任何 ability rawcode（多為攻擊/傷害事件引擎、周期環境效果）；root 事件已記錄 |
| **hero-bound 無 spell id** | 20 | trigger 用 `GetUnitTypeId(GetTriggerUnit())=='E002'`（英雄單位）當條件——效果綁**英雄**不綁技能；英雄名與 unit code 已逐列記在 reason（批 2 可走 ambient-vfx 綁英雄那條路） |

⇒ 176 列裡 **131 列（74%）根本不是技能驅動**（法器 69 + 地圖擺設 62）——
「442 列 join 不到技能」有將近三分之一是**本來就不該 join 到技能**。

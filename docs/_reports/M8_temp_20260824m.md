# M8 — #561 地面貼圖快取上限 ＋ #560 四個清理邊界共用清單（2026-08-24）

## #561 地面貼圖跨回合快取沒有上限

### 量到的（⛔ 不是推測）
- 出貨地面風格 **7 種**、每種 4 張 512² PNG（albedo/normal/orm/macro）。
- 快取鍵是 `style@uvScale` ⇒ 同一種風格在不同 `boundaryRadius` 的區是**不同鍵**，
  所以出貨 13 張場地的上界是 **≈13 組 × 4 張 = 52 張常駐**。
- 含 mipmap 一組 ≈ **5.6 MB** ⇒ 上界 **≈73 MB VRAM**，而 `AdaptiveQuality` 的降級階梯碰不到它。
- 商店預熱（`warmGroundTextures`）會在**第一個中場**就把每一種風格都抓進來 ⇒ 52 張在第一個商店全部到位。

### 做了什麼
| 住處 | 內容 |
|---|---|
| `content/config/vfx-cleanup.json` | `groundTextureCacheMax: 8` · `groundTextureCacheMaxMobile: 4`（＋ note 一段） |
| Zod `schema/config/vfxCleanup.ts` | 兩格 `.optional()` int + `GROUND_TEX_CACHE_BOUNDS = {min:4, max:64}`（**唯一**住處）＋ `DEFAULT_VFX_CLEANUP` |
| `apps/admin/src/configForms.ts` | 兩格欄位說明（寫「它影響什麼」，出貨值用 `{{出貨值}}`） |
| 消費端 | `vfx/vfxCleanupPolicy.ts::groundTextureCacheMax(mobile)` → `render/groundTextureCache.ts` |

**我挑的出貨值與理由**（owner ⛔ 沒有給任何數字 —— 2026-08-23「沒做完以前別問我了自己判斷 但是留後台開關可以簡易 rollback」）：
- 桌機 **8 組**（≈45 MB）：出貨只有 7 種風格,8 組讓「同一種風格的兩個半徑變體」也放得下 ⇒ 正常一場**幾乎不淘汰**，而 13 組的上界被擋在 8 ⇒ ≈73 MB → ≈45 MB。
- 手機 **4 組**（≈22 MB）＝下界：一張場地最多兩個鍵 ⇒ 4 組 = 當前這張 + 上一張。
- **rollback**：兩格都拉到上界 **64** ＝ 完全不淘汰（逐位元回到這一版之前）。

### 兩條正確性規矩（⛔ 不是品味）
1. **淘汰永遠不碰剛拿到的那一組**（`evictTo(cache, cap, keep)` 的 `keep`）——
   它下一行就要掛上材質，dispose 它 = 逐位元回到 GH#536 的**地板全黑**。
   同理下界是 **4** 不是 1：一張場地的兩個區半徑不同時是兩個鍵。
2. **預熱不更新「最近用過」、而且永遠不淘汰**：預熱一輪就把正掛在材質上的那一組推成 LRU
   的話，下一次淘汰會 dispose 它；滿了就**不再預熱**（⛔ 不是抓下來再丟 —— 那樣網路與解碼成本一毛沒省）。

## #560 出口／入口／每回合進商店前 —— 一份共用清單

- `RoundEdge`（2 個）→ **`CleanupEdge`（4 個）**：`entry`（進場組裝／進練習模式）·
  `enter`（開打）· `leave`（進商店）· `exit`（離場）。
- `RoundFxRegistry.add(name, reset)` 的**預設是四個邊界全跑**（owner：「寧願多次清理乾淨 也不要漏清到」）；
  只跑某幾個邊界要走 `addScoped(name, edges, why, reset)`，**`why` 是必填 ⇒ tsc 擋住沒有理由的例外**。
  兩列例外：`victoryFx`（`leave` 清它 = 刪掉 #235）與 `lifecycleLedger`（它是量測不是回收）。
- **入口**：`createRoundFx()` 最後 `registry.resetForRound("entry")`。
- **出口**：`RoundVfxLifecycle.exit()`，接在 `GameApp.dispose()` 的 `sessions.dispose()` **之後、
  那一長串 `dispose()` 之前**（順序是必要的：那些是釋放，這一行是把共用池與 module 單例先還回去）。
- **fail-loud**：扇出逐列 try/catch —— 一列擲例外⛔ 不可以帶走它後面每一列，但 `errorCount` /
  `lastErrorText` 記著且第一次 `console.warn`。

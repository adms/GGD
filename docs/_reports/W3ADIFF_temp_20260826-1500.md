## 4. 🔴 漏翻 C —— 引擎**有標籤**而出貨內容**零支使用**（7 個 kind）

`packages/shared/src/content/schema/effects/` 宣告 **46 個 effect kind**，出貨的 421 支技能只用到 **39 個**。零使用的：

```
carry  convertTeam  evasion  pull  revive  shieldBreak  summon
```
⭐ 而 w3a 那邊**有技能需要它們**（關鍵字比對 w3a ubertip vs GGD 三個住處）：

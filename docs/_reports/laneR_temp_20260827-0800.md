### ⭐ 我改的形狀與票上寫的**不一樣**，而理由是量到的

#635 的裁決留言寫的是「`h02u.w` **不動**、`h02u.e` 還原成 `67928acd^` 那一份」。
我**先照著做了**，然後量到它會**弄紅一條出貨的閘**：

```
== abilityCodeParity 新增漂移（會紅）: 11
   + 92-03|castTimeSec  + 92-03|castType  + 92-03|cooldown  + 92-03|cooldownTier
   + 92-03|effects      + 92-03|manaCost  + 92-03|manaCostTier
   + 92-03|passive      + 92-03|range     + 92-03|rangeTier + 92-03|targetsEnemies
```

原因：那個做法只把**編號**擺回去，卻讓 `92-03` 的兩份文件變成**兩支不同的技能**
（本體 `h02v.w` 是 owner 重製的吞噬被動，變身殼 `h02u.w` 是 w3x 匯入的「現有金錢\*0.1」主動）。
而 `abilityCodeParity` 的檔頭逐字寫著「⛔ 不要把它加進 baseline 了事」⇒ **那條路走不通**。

### ⇒ 改成：變身殼的 W/E **對齊本體**（機制整份，`id`／`icon` 留自己的）

| `content/champions/godie-h02u.json` `abilities.W/E` | 同上 | 內嵌鏡射（standalone → embedded，去掉 `schema`） |

**為什麼這是階梯上對的那一邊**：`h02v.{w,e}` 的 `provenance` 是 **`owner-spec`**（第 1 層，
owner 的新版技能說明），`h02u` 帶的是 **`w3x-import`**（第 3–5 層）的舊殼。

「本體改了、變身態沒改 ⇒ 玩家變身之後用的是舊的那一份」。

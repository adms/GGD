## 我挑了什麼（決策點與出處）

| 決策 | 挑了 | 出處／理由 |
|---|---|---|
| `charges` 住哪 | **授予格**（`statusImmunity.charges`，票文的設計），⛔ 不是 status 文件的一格 | `applyStatus` 沒有 `permanent`（`duration ?? 0` ⇒ 同 tick 到期），填任何秒數都是近似；授予騎在來源上、來源拔掉護盾就沒了，⛔ 不需要第二個時鐘 |
| 護盾多久 | `permanent` ＋ `exclusiveGroup:"spell-shield"`（預設 replace） | w3a `duration:{}`、stock `Dur1 0`：沒有秒數、擋下才消耗；再放一次換一層新的（票文 Known risks 的「疊兩份」由互斥組關掉） |
| 擋下後要不要動冷卻 | **不動** | GGD 的 Q 是主動技，`cooldown` 在施放時已付；原作 `Cool1` 是被動的 recharge，對應到的正是 Q 自己的冷卻那一格 —— 它已經是欄位，⛔ 不另開開關 |
| 什麼算「負性魔法」 | `tags:["debuff"]`（30 份出貨狀態帶它；`moon-combo` 等 buff 不帶） | 從資料推導；作者可改成 `cc` 等任何類別 |
| 誰的法術才算「對方」 | 施加者**隊伍不同**（`world.team`）；自己 ⇒ 不算 | 卡面逐字「對方」；WC3 Spell Shield 擋的是敵人的法術。⛔ 沒做成開關：想不出第二種讀法（自己的代價型減益打破自己的護盾對玩家無法解釋） |
| 常駐免疫＋一次性護盾同時在 | 常駐先答、不消耗 | 一份本來就掛不上來的狀態不該吃掉護盾 |
| 玩家看得到的那一拍 | `immune`（＋照舊 `immuneControl`） | `immuneControl` 在 `apps/client/src/vfx/worldCues.ts` 的 `WORLD_CUE_OUT_OF_SCOPE` 裡**零消費端**（寫下來的決定）；`immune` 有真的消費端（`net/RoomConnection.ts` → 打擊點「免疫」浮字） |

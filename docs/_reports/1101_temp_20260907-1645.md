## ⑤ AC③ 沒做的理由（⭐ 不是忘了，是一次**柵欄衝突**）

**前提查證過**：`skillremake:json` 的 127 份 writes **全部是 444**
⇒ `python3 tools/skill-remake/batch1.py --no-build` 確實會吃 EACCES。
（⛔ 我**沒有**去跑它 —— 跑它會寫 `content/**`，那是別條 lane 的柵欄。）

**正解的形狀**（照 genrun 既有的 wrapper/raw 慣例）：

```jsonc
"skillremake:json:no-build":     "bash scripts/genrun.sh skillremake:json skillremake:json:no-build:raw",
"skillremake:json:no-build:raw": "python3 tools/skill-remake/batch1.py --no-build",
```

⛔ **而它會弄紅 `apps/content-api/src/editorSourceSurvivesSync.test.ts:195`**：

```ts
["skillremake:json:no-build", "tools/skill-remake/batch1.py --no-build",
 rootScripts["skillremake:json:no-build"] ?? ""],   // → expect(actual).toContain(mustRun)
```

那條 pin 逐字比對**根 package.json 那一格的字串**，而 wrapper 之後那一格是
`bash scripts/genrun.sh …` ⇒ 🔴。修它要動 `apps/**` —— ⛔ 本 lane 的硬性禁令。

⇒ ⭐ **三行就做得完，但要有 `apps/**` 的柵欄**：上面兩行 ＋ 把那條 pin 的第一、三欄
改成 `skillremake:json:no-build:raw`。票文自己寫著這一項是「便利性，⛔ 不是阻塞」，
所以我**停在這裡並指名它**，⛔ 沒有偷偷用註解去騙過那條 pin（那會讓 pin 變成一句謊話）。

### 移動迴圈 `DarkDragonEXMove`（週期 **0.08 秒**）

- `DarkDragonCount < 14` ⇒ **13 步**，總時長 ≈ **1.04 秒**
- ⭐ **蛇行**：`Count % 2 == 0` → 朝 `facing **+35°**` 推 130；否則 `facing **−35°**`
  ⇒ 淨位移沿面向，橫向左右扭 —— 那就是「黑龍」的形
- 側龍：`±25°` 下令 + 位置推 `±(10 + **rand(5,60)**)°` ⇒ 隨機外擴（⛔ 不是直線）
- 每步生一具 `h02E` **黑龍身體** `BlackHole.mdl` scale 0.1 留在原地 ⇒ **尾流由 13 具靜態模型組成**
- 每步在 `DarkDragonPoint` 放 `Boomnl.mdx`；偶數步另在龍頭周圍 **750×750** 隨機點放 `WarStompCaster.mdl`
- ⭐ **碰觸**：`GetUnitsInRangeOfLoc(**250**, 主龍點)`（側龍 200 / 250），
  閘是 `IsUnitInGroup(...) == false` ⇒ **同一個人只被收一次**，收進 `DarkDragonGroup` 並在 chest 放 `Boomnl.mdx`

### 結算（Count 到 14）

- ⭐ **傷害不是碰到當下付的** —— 整條路徑的名單**存到最後一次性結算**
- EX（U010 + EX_Mode）：**2500 固定**；否則 `400 + 250 × level` = **650/900/1150/1400**，皆 `DAMAGE_TYPE_MAGIC`
- `TriggerSleepAction(1.5)` 後清掉 `o00Z` / `h02E` / `h02F`

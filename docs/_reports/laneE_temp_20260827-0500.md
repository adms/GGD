## ✅ #718 關了（**帶終端證據**）

### 缺陷

`apps/client/src/render/occlusionZone.ts:87`

```ts
const live = activeObstacles(zone.obstacles, undefined, 0);
```

`activeObstacles` 的第一行是 `if (schedule === undefined && held === undefined) return obstacles`
⇒ **原樣回傳** ⇒ 每一道門在遮蔽上**永遠算關著**。tsc 綠、既有守衛全綠（失敗形態⑧：
消費端存在，但它讀的那一格沒有寫入端）。

### 修法

```ts
const live = activeObstacles(zone.obstacles, gateScheduleOf({ zones }), tick);
```

* `tick` 是**必要參數**（⛔ 沒有預設值）—— 給 `= 0` 等於留一個不會紅的後門。
* 排程走 `gateScheduleOf`（GH#397 的唯一來源），⛔ 不是 `zones[0]?.gates`。
* 呼叫端 `GameApp.occludeArgs` 傳**權威** `state.tick`（⛔ 不是 `renderTick`）。
* ⇒ 取牆規則與伺服器 `BasicAttackSystem.seesTarget` **逐字相同**。

### 終端證據

`apps/client/src/render/occlusionGate.test.ts`（`@visual-proof`，3 條）——
出貨 arena 文件 → `arenaDefFromDoc` → 出貨 `occludeArgsFor` → 出貨
`EntityViewRegistry.sync`（NullEngine）→ 讀 `view.root.isEnabled()`。

| tick | 來源 | 斷言 |
|---:|---|---|
| 0（`west_door` 關） | `closedGatesAt(SCHED, 0)` | `isEnabled() === false` |
| 900（`west_door` 開） | `closedGatesAt(SCHED, 900)` | `isEnabled() === true` |
| 兩者 | 非 gate 的牆 | 都擋（AC3） |

⛔ 零字面 tick、零字面座標。`scripts/visual-proof.sh` EXIT=0（「畫面層有改動，而且帶了終端證據」）。

### 突變

`gateScheduleOf({ zones })` → `undefined`
⇒ 「門開著（tick 900）⇒ 看得到」紅：`west_door 開著卻還在遮 —— 門的狀態沒接進來`。
`cp` 備份還原（⛔ 不是 `git checkout`）。

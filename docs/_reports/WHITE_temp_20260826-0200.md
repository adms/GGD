## 1. 選了哪條出路，為什麼（票的 Implementation constraints 點名要寫）

票給了兩條：**(a) TexStats 側車** vs **(b) 抽取器呼叫同一支 TS**。⭐ **選 (b)。**

| | (a) 側車 | ⭐ (b) 呼叫同一支 TS |
|---|---|---|
| 搬過邊界的是什麼 | **資料**（每張貼圖的 256×3 表） | **判準本身**（δ 的代數 ＋ 門檻 ＋ 那句話） |
| python 那邊還剩什麼 | ⛔ **δ = a·col.a·(1 − (L/255)·col.rgb) 這一行仍然要抄一份** | ⛔ 什麼都不剩：它只 marshal `(貼圖路徑, 顏色梯度)` 進去、拿 `{delta, reason}` 出來 |
| 多幾份產物 | ⛔ 多一份側車 ＋ 一條它自己的過期閘（貼圖換了側車就過期） | 0 |
| 成本 | 產生側車 | 一次 `node_modules/.bin/tsx` 子行程，實測 **0.6 秒**，⭐ 每個模型批次呼叫一次 |

⭐ **決定性的理由**：GH#709 更正的**不是一個數字，是那一行混色代數**
（`(DST_COLOR, ONE_MINUS_SRC_ALPHA)` → `(DST_COLOR, ZERO)` ＋ shader 先 premultiply）。
側車只把**資料**變成單一住處，⛔ 而會漂的那一半（代數）仍然有兩份 —— 那正是這張票的缺陷本人。

⚠️ **代價（誠實）**：抽取器現在需要 `node_modules/.bin/tsx`。⛔ 沒有 fail-open ——
tsx 不在、貼圖找不到、oracle 非零離開，三種都 `SystemExit` 並指名，
⛔ 不退回一個近似判準（「靜默跳過」與「通過」長得一模一樣）。
⭐ `--emitter-order=file` 這條 rollback **刻意不吃這個相依**：判準呼叫排在 `file` 的
early-return **之後**，一條需要 toolchain 的 rollback 不算 rollback。

## 3. A/B 像素證據（⛔ 不是「換上去了」）

**台子**：`beam-audition.html`（`client-beam` :39673）走出貨的 `toParticleSystem` ＋
出貨的 `content/vfx/*.json`。⭐ 量尺先自證：`calibrate()` 全亮 quad = **462,400** 亮像素 > 0。

⭐ 這一批**多加了一把尺**（`probeDocs`，差分）。⚠️ 原因是硬的：
`bright/lit` 只問「畫面**變亮**了嗎」，而 modulate 在算術上**只會變暗**
（`out = dst·(1−δ)`）⇒ 一支完全正常的 modulate emitter 在近黑台子上永遠讀 0，
**而那個 0 是台子的性質，⛔ 不是文件的性質**。差分尺量「有幾個像素跟對照幀不一樣」
與「總共差了幾個 code value」，加法與乘法在這把尺上可比。

## 5. ⚠️ 誠實邊界（量到但**不**宣稱）

1. **本批沒有改變任何玩家看得到的東西。** `p00–p02` 位元組不變 ⇒ 13 支 `mark` 家族技能
   在畫面上與昨天**逐像素相同**。⭐ 本批交付的是「判準不再說謊」＋「兩支 emitter 不再被刪」。
2. `p03`/`p04`/`p05` **出貨了但播不到** —— `MAX_STOCK_EMITTERS_PER_MODEL = 3` 只問 `p00..p02`
   （⛔ 本批不動那個上限）。它們的價值是：哪天窗開到 4/5，候選名單是**完整**的，
   而且側車記著每一支的 δ 與 PRE2 index。
3. **A/B 是逐份文件的孤立讀數**，⛔ 不是一場真比賽的合成畫面。真的場景裡 022222 的紅火星
   與 white03 的暗煙**會疊在 p00 的巨環上**，而環本身就有 10 萬個亮像素 —— 第三格的貢獻
   在合成畫面裡比這張表看起來更小。⛔ 我沒有量合成畫面。
4. **`lit` 幕布是中灰常數（dst≈128），⛔ 不是真的地板**。modulate 的效果與 dst 成正比，
   所以 §3 的 modulate 讀數是「一個代表性亮度」下的值，⛔ 不是遊戲裡的期望值。
5. **δ 只涵蓋 `vfx@1` 粒子**。`ribbon@1` 的 modulate 走另一條合成式（`ribbonMath.ts` 的
   `toWhite` 手工淡出），⛔ 這條判準不套它 —— 這是判準⑤ 原本就寫著的界線，本批沒有擴。
6. ⛔ **沒有動 `--min-refs`**（票的 Non-goals）。

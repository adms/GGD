owner 說「技能說明記得改，不然之前都是寫未實作」。翔封界那兩份 JSON 的
`description` 裡**一個「未實作」都沒有**（2026-07-30 就改寫過了）。真正印那句話的是：

```
apps/client/src/ui/passiveSlot.ts:99   INNATE_INERT_NOTE = "天生被動 · 效果尚未移植（目前無作用）"
```

判準是 `passiveSlot.ts::passiveRankGrantsSomething()`，它**只看三格**：


### 交回的補丁（`apps/client/src/ui/**` 是別的 lane 的，⛔ 我沒有動）

```ts
// apps/client/src/ui/passiveSlot.ts
function passiveRankGrantsSomething(def: { passive?: { ranks: readonly unknown[] } }): boolean {
  const rank0 = def.passive?.ranks[0] as Record<string, unknown> | undefined;
  if (!rank0) return false;
  // ⭐ 三格 → 全部酬載。⛔ 不要再抄一張手寫名單:`modifiers`/`hooks`/`auras`
  //   以外的每一種（flight / vision / block / attributes / whileForm / …）
  //   都是 syncAbilityPassives 真的會掛上的東西。
  //   判準改成「rank0 除了空陣列以外還有沒有東西」。
  return Object.entries(rank0).some(([, v]) => (Array.isArray(v) ? v.length > 0 : v != null));
}
```
⚠️ 突變驗證方式：把 `godie-hjai.passive` 丟進去 → 應為 `true`；
把 `godie-hapm.passive`（真的空的）丟進去 → 應為 `false`。

## ① #572 —— 翔封界：說明改了、飛行視覺做了 ✅

owner 2026-08-23 逐字：「**飛行視覺可以調 3d model 高度與影子變化**」
⇒ **照他說的兩件事做，⛔ 沒有自己加粒子／翅膀。**

### 卡面（`godie-hjai.passive.json` ＋ 鏡射 `godie-h020.passive.json`）

- ⛔ 拿掉「離地 **0.45 單位**」—— 那是 `flight.hoverHeight` 的**第二個住處**
  （第〇·四守則），級距一改它就變謊話。
- ⭐ 補上**會發生而卡面沒說**的一句（第一·五守則的反向那一半）：
  「位移也跟著穿過去：她走得過的牆，衝刺／瞬移／跳躍也跨得過」
  —— 那是 GH#490 `wallBlock.flightExempt` 出貨 true 的真行為，卡面在此之前沒提。
- ⭐ 補上視覺的讀法：「身體整個離地浮著，地上的影子跟著縮小、變淡」。

### 高度（3d model 高度那一半）

`passive.ranks[0].flight.hoverHeight` **0.45 → 0.9**（TARGET_HEIGHT = 1.8 ⇒ 半個身高）。
值住在**內容文件**裡（後台 content overlay 可改），上界由
`FLIGHT_MAX_HOVER_HEIGHT = 6` 的 Zod 守著。

### 影子（影子變化那一半）

出貨的跳躍曲線 `1 / (1 + h × 0.15)` 在 h = 0.45 是 **0.937** —— **影子只縮 6%**，
那就是「看不出來在飛」的量化原因。現在飛行走自己的曲線：

| 住處 | `packages/shared/src/sim/flight.ts` |
|---|---|
| `FLIGHT_SHADOW_SHRINK_PER_UNIT` | 0.9 |
| `FLIGHT_SHADOW_MIN_SCALE` | 0.45（影子是**位置提示**，⛔ 不可以縮到不見） |
| `FLIGHT_SHADOW_BASE_ALPHA` | 0.38（＝出貨落地值） |
| 出口 | `flightShadowResponse(h)`（純函式，符合 `sim/purity.test.ts`） |

量到的：h = 0.9 ⇒ 影子 **0.55×**、alpha **0.21**（落地 0.38）。⭐ 看得出來了。

⚠️ **飛行與跳躍分得開**：飛行刻意**不點** `ENTITY_FLAG.AIRBORNE`
（`sim/flight.ts` ②：在飛的人要保留跑步動畫），所以客戶端的判準是
`h > 0 && !airborne`。⇒ #247 跳躍那條路**逐位元不變**，
`growthTier.test.ts` 那條 `1 + h × 0.15` 照樣綠。

### ⛔ 為什麼三格是常數而不是 `config.flight-visual@1`（第一守則的例外，帶理由）

一份新的 `content/config/*.json` 需要**同時**動五個檔：

**這一批那五個檔全部在別的 lane 手上**（`git status` 逐檔確認過），

⇒ 三格**集中在一個住處**、由一個函式單一出口供應，

## ⛔⛔ 紅字①（GH#694）：出貨的雨在**真瀏覽器上一定擲例外**，而它會弄垮整張地圖

`w2_shipped_path_throws` 是在**真的 WebGL2 瀏覽器**上量到的，⛔ 不是推論：

```
buildRain → new GPUParticleSystem(...)
  Error: The WebGL2ParticleSystem class is not available! Make sure you have imported it.
```

| | |
|---|---|
| **根因** | `apps/client/src/vfx/WeatherRainFx.ts:157` 在 `GPUParticleSystem.IsSupported` 為真時走 GPU 路，而**全 repo 沒有任何檔案** `import "@babylonjs/core/Particles/webgl2ParticleSystem"`（`grep` 過：客戶端只 import `particleSystem` / `gpuParticleSystem`） |
| **為什麼測試是綠的** | NullEngine 的 `IsSupported` 是 **false** ⇒ vitest 一直走 CPU 那條路。⭐ `WeatherRainFx.ts` 的**檔頭自己寫著這件事**（「NullEngine 沒有 ⇒ 測試量到的是 CPU 那條路」）—— 知道，但沒人把它變成閘 |
| **爆炸半徑** | 出貨呼叫點 `ArenaScene.ts:459` 的 `buildRain(...)` **沒有 try/catch** ⇒ **擲中雨的那一場（出貨 `rainChance 0.3`，約三成室外場）整個 `buildArena` 拋出**。⛔ 不是「沒有雨」，是**地圖建不起來** |
| **修法（一行 ＋ 一條閘）** | ① `WeatherRainFx.ts` 補 `import "@babylonjs/core/Particles/webgl2ParticleSystem";`；② `buildRain` 內部對 GPU 建構包一層 fail-safe 退回 CPU 路（fail-open 沒錯，**靜默**才是缺陷 ⇒ 退回時要有人喊）；③ 閘要在**真 GPU** 上跑，⛔ NullEngine 驗不到 —— 這一頁（`?scenario=weather`）就是那條閘的位置 |
| **⛔ 本 lane 未修** | `apps/client/src/vfx/WeatherRainFx.ts` / `render/ArenaScene.ts` 不在本 lane 柵欄內。⛔ 也不 gh 寫入 ⇒ **請主 session 開票**（建議掛 GH#694，T0） |

### ⭐ 五個踩出來的台子教訓（下一個做 audition 的人請直接抄）

1. **粒子時間要 `scene.useConstantAnimationDeltaTime = true` ＋ 自己畫幀，⛔ 不要 render loop。**
   血花壽命 **0.22–0.62 秒**，而「量→PNG→POST」一張要 0.3–0.8 秒 ⇒ 用牆鐘的話
   **第二張圖上血就散光了**，一個好好的特效會被量成「只有出生那一幀看得到」。
   （改成逐幀之後，同一發血花從「d2 有、d3 起全 0」變成 d2 2,615 / d3 2,402 亮像素。）
2. **`engine.beginFrame()/endFrame()` 不可以省。** 只叫 `scene.render()` 的話，
   一場 **1,200 顆活粒子**的雨在畫面上是**零像素**（GPU 粒子的雙緩衝靠它推進）。
   ⇒ 這是「量尺說看不見」而**其實是量尺壞了**的第二種樣子。
3. **第一張截圖之前要 `scene.whenReadyAsync()`。** 材質還在編譯時 `render()` 靜默跳過
   那顆 mesh ⇒ 基線量到 0，而畫面上明明有東西（坑③的變形）。
   ⭐ 另外：`?t=${Date.now()}` 是必要的 —— 沒有它，改完模組重新導覽仍然拿到**上一版**
   transform（連續兩輪的錯誤行號對不上檔案才發現）。
4. **一組連續圖片裡⛔ 不可以有重複幀。** 第一版的脫困 s3 取在「放行後 30 tick」，
   而那正好是他們走完全程的時間 ⇒ s3 與 s4 **sha1 一模一樣**，等於少一張證據。
   ⭐ 收工前對每一批 `shasum *.png` 掃一次重複 —— 順帶還抓到了紅字③（w6 ≡ w5）。
5. **⛔ 不要跟別人共用瀏覽器分頁。** 第一輪跑到一半，另一條 lane 把同一個 tab
   導去 `beam-audition.html`，六分鐘的內容載入全部作廢 ⇒ 之後一律自己 `tabs_create`。

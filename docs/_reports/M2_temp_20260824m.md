那樣只會把一張**會過期**的表留在文件裡變成**手寫散文** —— 正是這支產生器存在的
理由的反面（`gen_contract_numbers.py` 的檔頭記著它當初就是這樣長出四個假數字的：

⇒ ⭐ **退場也是產生器的工作**。`tools/editor-contract/gen_contract_numbers.py` 加了
`RETIRED` ＋ `retire()`：

| | |
|---|---|
| 刪什麼 | 標記所在的**那一整章**（`##` 標題 → 下一個 `##` 標題之前），⛔ 不是「兩個標記之間」——只刪表格會留下一個標題與一段介紹**不存在的表**的散文 |
| 連帶 | 目錄裡指向它的那一行（⛔ 否則是一條指向不存在錨點的**斷鏈**）。比對是**逐字標題**，⛔ 不做模糊猜測 |

| 死碼 | `ENV_ROWS` 與 `table_env()` **整個刪掉** —— 留著一支沒有人呼叫的產生函式，下一個人只要把名字加回 `BLOCKS` 就把整章復活了，而 ⛔ 沒有任何東西會紅 |

## #612 —— `tools/hero-archetypes/build.ts` 補 `--check`

它在 `skills:sync` 裡、寫**兩份 git 追蹤的 `docs/`**，⛔ 而 `skills:check` 問不到
它是不是最新的 ⇒ 產物可以**無聲過期**。

* `--check` 是**唯讀**的，逐位元組，**兩份都比對完才回報**（只報第一份會讓下一個人
  修完再跑一次又紅一次，而他不知道還有第二份 —— 同 `contract:numbers` 的理由）。
* ⛔ **零時鐘欄位**：`SPEC_DATE` / `SPEC_VERSION` 本來就是寫死的常數
  （`caps:export` 的同一個理由 —— 一個會隨時間變的欄位會讓比對永遠不相等，
  於是 `--check` 只能被放寬，而被放寬的閘等於沒有閘）。
* `package.json`：新增 `archetypes:check`，接進 `skills:check` 尾端。
* `skillsSyncCoversGenerators.test.ts` 的 `GENERATOR_NO_CHECK["hero-archetypes"]`
  那一列**刪掉** —— ⛔ 留著一列說「這是個洞」的豁免，下一個人讀到的是「這裡沒事」。
* 順手更正檔頭一句**在說謊**的註解（第三守則）：它寫著產物是
  `docs/hero-archetypes.md`，⛔ 那個檔不存在（真的是 `docs/英雄定位與屬性總表.md`）。

**突變（做了）**：`printf ' ' >> docs/hero-archetypes.json` → `archetypes:check`
**exit 1** 並指名那一份；`archetypes:build` 重生成 → exit 0 且 `git diff --stat` 空的
（⇒ 產生器是決定性的，還原**沒有**用 `git checkout`）。

## #566 —— `refs.ts` 少了三條 ref edge

參照完整性表**漏掉**的那幾格 ⇒ 打錯一個字在**載入時一個字都不會說**，
而畫面上「指到不存在的資產」與「這支技能本來就沒有那個效果」長得一模一樣（失敗形態②）。

| 新增的 edge | 硬/軟 | 理由 |
|---|:--:|---|
| `spawnModelFx.modelKey` → `models` | **HARD** | 同 `champions.modelKey` |
| `spawnModelFx.preset` → `ability-templates` | **HARD** | `modelKey` 缺席時由模板預設補 ⇒ 指不到模板連「該用哪一具模型」都問不出來。⚠️ 只驗一格是不對稱的 |
| `ability@1.persistentVfx[].vfxKey` → `vfx` | soft | schema 早就宣告成 `zRef("vfx", { soft: true })`（GH#539），⛔ 但這張表從沒把它抽出來 ⇒ 那個宣告對載入期是**裝飾** |

⭐ **先量再關**：出貨語料 9 個字面 `modelKey` · 3 個 `preset` · 2 個 `persistentVfx.vfxKey`，
**dangling 全部 0** ⇒ 這三條閘是在現況**已經乾淨**的時候關上的，
⛔ 不是拿一條 HARD 閘去追既有的債（那會在載入時退回骨架英雄）。

### editorCapabilities 那一半

`editorCapabilities.test.ts` **兩個方向已經關著**（宣告 unsupported 但引擎有 → 紅；
宣告 supported/partial 但引擎沒有 → 紅），它靠的是 `probe(fingerprint)`。
⇒ 這一半真正的洞是**散文**（capability 存在但描述在說謊），
而那正是 #613 的兩筆與新的 `editorContractSchemaTags.test.ts` 蓋掉的東西。

1. **自己那一側**：round 1 的 `world.mobRules.humanSeats` 是空的（`fromRound: 3` 之前走 `endCombatMobs`）
   ⇒ LoL 模型／`idleAutoEngageSec` 那一段的 `isHuman` 是 false ⇒ 索敵半徑是近戰地板 **6 u**；

2. **bot 那一側**：`beats` 是 kind → forced → threat → **hp** → 距離 —— 滿血、不出手的座位在任何一個
   受傷的隊友還活著時永遠排最後；等它是唯一的敵人，bot 才靠 `AI_ENGAGE_RANGE = 48` 走過來。

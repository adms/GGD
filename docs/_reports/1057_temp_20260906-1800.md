## 2. 做了什麼（單一住處）

### ① `packages/shared/src/content/schema/effects/spawnModelFx.ts`
- 新增 `MODEL_FX_PATH_FIELDS`：每條 `path` 的 `requires`（refine 必填）與 `reads`（sim 真的讀；逐字對 `modelFxPlacement.ts::modelFxInstancesFromFrame` 與 `sim/effects/spawnModelFx.ts`）。鍵集合由 `ModelFxPathName`（`sim/effects/variants/spawnModelFx.ts`，路徑型別唯一住處）`satisfies Record<…>` 逼滿。
- `MODEL_FX_PATHS` 從表鍵推導 ⇒ `z.enum(MODEL_FX_PATHS)`（⛔ 不再手抄一份給 Zod）。
- refine 的 path 相關 9 條 `if` 全部改讀 `modelFxPathReads()` / `modelFxPathRequires()`；**訊息與行為逐條保留**（orbit/static 的 lifeSec 訊息合成一條、依 path 分句）。
- 新增一條 refine：`spreadDeg` 只有 fan 讀 ⇒ 非 fan 填了就擋（`!fromPreset`）。⚠️ 出貨內容量到 **0 個**違規節點（`content/**` 掃過，只有 2 個 fan 節點帶它）⇒ 逐位元不改變任何上線文件。

### ② `packages/shared/src/content/templates/expand.ts`（只動 modelFx 段 ＋ 檔頭 import）
- `modelFxFamily`：合法 path ＝ 表的鍵（`Object.hasOwn`），⛔ 不再是 `!== "forward" && …` 鏈（GH#649／#916 兩次都是那條鏈沒跟上）。
- 七格 `speed / distance / lifeSec / spacing / anchor / count / spreadDeg` 每一格 `emits(f) = modelFxPathReads(path,f) && has(t,p,f)`，⛔ 不再是「static 一組／其餘一組」二分。
- 鍵順序保留改動前的 ⇒ **35/35 模板預設展開與 HEAD 逐位元相同**（拿 `git show HEAD:…expand.ts` 當對照跑過一次，臨時檔已刪）。
- 新增 `modelFxPathsFor(t)`：這份模板撐得起的路徑（`requires` 每格 `has()` 為真；static 另一條動態規則：宣告了 `count` 且 max≥2 就要有 `spacing`）。

## 三個斷點

1. **`compile.ts` 只從牆格推 `gateGroup`。** 而七張圖有六張把門寫成地板 `.`
   —— 而那是**對的**：基礎格網＝「門全開」，驗證器的 `gateTrapsPlayers` 正是把
   關上的門畫成 `#` 再驗連通。⇒ 合併牆格時門根本不存在 ⇒ 0 個。
   反方向也壞：門若真寫成 `#` 又貼著長牆，`mergeWalls` 把它吞進同一個盒 ⇒ `allSame`
   false ⇒ 一樣 0 個。**兩個方向都得到 0。**
2. **`ZoneDef` 沒有 `gates` 欄位。** 產生器逐字寫進 `arena@1` 的 `zone.gates`
   在 `arenaDefFromDoc()` 的逐欄位重建裡被靜靜丟掉。
3. **`world.gateSchedule` 的寫入端是零個。** 宣告成 `= undefined` 之後全 repo 沒有人
   指派它 ⇒ `activeObstacles(obstacles, undefined, tick)` 原樣回傳 ⇒ 門**永遠關著**。
   ⇒ 失敗形態⑧的教科書形狀：消費端（`MovementSystem` / `BasicAttackSystem`）都在，
   而它讀的那一格沒有人寫。

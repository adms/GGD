### M2 為什麼需要一支系統，而形態閘不用

形態閘靠 `ChampionFormSystem.setBody`（身體的**唯一寫入者**）重新求值。
⛔ 狀態沒有唯一寫入者：`effects/applyStatus.ts` 掛、`systems/StatusSystem.ts` 收、
【淨化】剝、回合重置清 —— **四個出口**。四處各補一行 = 第〇·七守則的「一行接線」病，
而漏掉的那一行**不會紅**（它長成「卍解結束了而格擋還在」，畫面上跟正常一模一樣）。

⇒ 改成**推導**：`packages/shared/src/sim/statusGatedPassives.ts` 每 tick 問
「該不該掛」（`rankBlock` **本人**，⛔ 不是抄一份判斷）與「掛了沒有」（`sc.sources`），
**只在兩者不一致時**才 `syncAbilityPassives`。

- ⭐ **無狀態** ⇒ replay seek / 跳過的 tick / 壓縮封包都不可能讓它漂掉。
- ⛔ **不是每 tick 無條件 sync**：那支是 detach+attach（兩邊都寫 `dirty`）＝ 每 tick 對每位英雄重算整份屬性表。整個重點就是那個 `!==`。
- 成本：出貨 0 份文件填 `whileStatus` ⇒ 今天是每位英雄每 tick 六次 `WeakMap` 查表。
- tick 位置 **0c**（`championFormSystem` 之後、`statRecomputeSystem` 之前）——
  兩個方向都承重：排在形態之前會用上一 tick 的身體算這一 tick 的答案；
  排在 recompute 之後會慢一格。

### M5 為什麼 ⛔ 不可以借 `root`

owner 2026-08-13：「應該是**狀態改變，類似定身**（可攻擊跟施展技能但不能移動），
並非把移動速度調整到 0」。而 `movementHold.ts` 檔頭**早就逐字寫下**理由：
`root` 是 **CC** —— 可被【淨化】剝掉、被免控 buff 拒絕、計進 `ccAppliedTicks` 戰績，
紮根三件事一件都不是。⭐ 掛在**來源**上就結構性地全部成立
（`StatsComp.sources` 不走 dispel、不走免控、不進 CC 帳）。

### ⚠️ 量到的一件會改變裁決的事（`primary` 今天是死的）

`attributes.primary` 在**引擎裡**唯一的消費端是 `perLevelBonusFor` 的
`appliesTo: "primary" / "nonPrimary"`，而出貨的 `content/config/per-level-bonus.json`
是 **`"all"`** ⇒ ⭐ **今天連英雄卡上那一格 `primary` 本身也不影響任何數字。**
⇒ 白木變身態的 **STR→INT 在出貨設定下是 0 影響**（v2 把它列為「退場會掉的東西」，
本輪量到它其實不掉）。要不要打開 `primary` 模式是 **owner 的旋鈕**，⛔ 我沒有動。

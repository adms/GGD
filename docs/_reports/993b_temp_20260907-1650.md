## ② 加了哪一格槽 —— ⭐ 每一格的出處

### `tpl-buff-self.params.perRank`（新）

```json
"perRank": { "type": "buffPerRank", "optional": true }
```

| 欄 | 值 | 出處 |
|---|---|---|
| `type` | ⭐ **新的 `zParamType` 成員 `buffPerRank`** | schema 就是 `zApplyBuff.shape.perRank` **本人**（`schema/effects/applyBuff.ts:260`，逐字註解「rank-indexed override (index rank-1, clamped) — WC3 buff columns are per level」）⇒ ⛔ **沒有第二個住處**（第〇·四守則） |
| `optional` | `true` | 出貨這個形狀 8 支裡 **5 支**帶 `perRank`（e001.q · e008.w · hapm.q · hpb1.r，加上產物側 emfr.w／h00l.r 的變體）、3 支不帶 |
| `default` | ⛔ **不給** | ⭐ 沒有 `default` ⇒ `templateDefaultsHaveOrigin.test.ts` 的 `needsOrigin()` 不叫它（那條閘只問「有 default 的格」）。⛔ **刻意不編一個** —— CLAUDE.md 記過 `tpl-beam-roll.count=6` 憑空來的那次 |

⛔ **為什麼不用既有的 `scaling` 型別**：`scaling.perRank` 是一串**數字**（傷害逐階），
而這一格逐階換的是**一整組 modifier ＋ 秒數** —— 22-01 第 4 階同時把 `+50%` 移速換成 `+150%`、
12 秒換成 45 秒（`content/abilities/godie-e001.q.json` 的原始 `perRank`）。一串數字表達不了。

⛔ **為什麼不拆成散裝參數**（`rank2Duration`／`rank3Modifiers`…）：出貨的階數是 3–5 不等，
拆開就是把 `modifiers` 抄 N 份，而那是第〇·四守則直接禁止的形狀。

### ⭐ 第二個機制：**演出節點留在文件裡**（⛔ 不是新槽）

`applyStatus + damage + spawnModelFx`（4 支）那一族的正解**不是**替家族加一組 modelFx 參數 ——
`expand.ts` 自己逐字寫著為什麼（就在 `mergeExpansion` 上面）：

> 行為模板（45 份）× 演出（locust 五族）是一個**外積** —— 逐族加參數等於把
> 第零守則⑨的「N 個同型」搬進模板層。⇒ 兩者**正交**才對。

而 `mergeExpansion()` 從 2026-09-02 起對「展開**沒有**產出的 kind」是**保留**的。
⇒ ⭐ 缺的不是引擎機制，是 **`templatize.py` 從來沒問過第二輪**：
「把演出節點拿掉之後，剩下的行為配得上哪一個模板？」

落地（`tools/skill-remake/templatize.py`）：
- `PRESENTATION_KINDS = {spawnModelFx, spawnVfx, screenShake, screenFlash, floatingText}`
  —— ⭐ 判準是「它會不會改變任何一個數字或狀態」，⛔ 不是「它看起來像不像特效」。
  `damageArea`／`blink`／`dash` 留在文件裡是**設計決定**（`godie-etyr.r` 那三份），⛔ 不是正規化。
- `match_any()` 第二輪：第一輪不中 ⇒ 拆掉演出節點再問一次；中了就把它們**留在 `effects` 裡**。
- `with_template(doc, ref, params, keep)`：`effects` 換成 `keep`（⛔ 不再一律清空）。
- ⚠️ 「展開自己也產出同一個 kind ⇒ merge ⛔ 不保留」那條性質 Python **驗不到**
  （它不跑展開器）—— ⭐ 由 `templatizeEquivalence.test.ts` 定案（見突變②）。

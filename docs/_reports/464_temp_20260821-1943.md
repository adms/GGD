## 3. 為什麼它自動解掉 —— 是**機制**，⛔ 不是有人逐支手改

`tools/skill-remake/tierize.py:543` 一段十行的規則：

```python
positive = [x for x in cd if isinstance(x, (int, float)) and x > 0]
if positive:
    shape = cooldown_shape(doc)
    grid  = grids.cd_row(shape)
    ci, why = snap_index(float(positive[-1]), grid, idx)   # ← 參照階 = 滿階
    doc["cooldownTier"] = TIER_NAMES[ci]
    doc["cooldown"]     = [grid[ci]] * len(cd)             # ← 每一階同值
```

⇒ 「逐階不同」這個形狀在**寫入的當下**就被消滅了。這正是第〇·五守則的兩層：
機制住引擎/工具，內容只填一格級別。

## 4. 🔴 唯一還錯的那一支：25-01 北斗懺悔拳（×2 卡）—— **級距是從錯誤值推出來的**

### 根因（可以逐位元重現）

參照階是 **`positive[-1]`＝滿階**。而票裡點名的 5 支資料錯，錯的位置不一樣：

| 技能 | 錯在哪一階 | 參照階（滿階）拿到的是 | 結果 |
|---|---|---|---|
| Avalon `[12,60,60]` | rank1 | 60（乾淨） | ✅ 自癒 —— 錯的那一階根本沒被讀 |
| 雙龍紋 `[12,60,60,60]` | rank1 | 60（乾淨） | ✅ 自癒 |
| 暗步 `[4,3,2,1]` | 整條偏低 | 1 → 低於下限⇒夾 | ✅ 被**下限**救回（6 卡面秒 = 1.2 實際秒，不再是 0.2） |
| 界王拳 `[45,45,45,45,57]` | **滿階** | **57**（錯的） | ✅ 巧合無害 —— 57 與 45 都落在「大」 |
| **北斗懺悔拳 `[25,25,25,25,8]`** | **滿階** | **8**（錯的） | 🔴 **極小(6)**，而乾淨值 25 → **小(15)** |

跑出貨的 `snap_index` 逐支複驗（`tierize.py` 自己的函式，⛔ 不是我另寫一份）：

```
godie-u00l.q  25-01 北斗懺悔拳  單體  idx=0   用 8 -> 極小(6.0) | 乾淨 25 -> 小(15.0)  🔴 POISONED
godie-umal.q  25-01 北斗懺悔拳  單體  idx=0   用 8 -> 極小(6.0) | 乾淨 25 -> 小(15.0)  🔴 POISONED
```

⇒ 票裡寫「最高階突然掉到 8（−68%），前四階完全不動」的那個 **8**，
不只沒被修掉，它還**變成了全五階的唯一依據** —— 4 階的 25 被它拉成 6。
玩家端：**5.0 實際秒 → 1.2 實際秒，冷卻縮短 4.2 倍**，而 `content:build` 綠、全套測試綠。

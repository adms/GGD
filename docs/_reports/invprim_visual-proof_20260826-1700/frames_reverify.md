## 八、⛔ 誠實邊界（⛔ 不可以省）

   ⛔ **我沒有調任何一個門檻**；主尺與 BEAMVERIFY2 逐位元相同（原作四張重算的數字完全一致）。
2. ⭐ **主尺在 20-03 的 t43–t75 讀到 9–78 px ⇒ 那三格的 `aspect/gaps/hue` 主尺欄是空的。**
   我用 R3（A/B 差分遮罩）補上，⛔ 但那是**另一把尺**：它的絕對數字
   ⛔ **不可以**跟原作那一列並排讀，只能讀「落在哪一帶」。
3. ⭐ **A/B 的噪聲地板是量出來的，而它在某些格子吃掉了整個效果**：

4. **原作與 GGD 的絕對亮像素數不可比**（解析度／場景／背景全不同）。
   可比的只有 `aspect` / `gaps` / `bins` / `hue` / `sat` / `暈:核` / **lum 中位數**

   一項都沒量到。⭐ 原作那道光束**照亮了草地**，黑場永遠量不到這一項 ——
   而它很可能正是「粗」的觀感來源之一。

   90-04 也吃 `revivehuman` ⇒ 靜態上同族。⚠️ **這句是推論，⛔ 不是量到的。**

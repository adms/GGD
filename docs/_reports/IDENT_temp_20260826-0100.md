## 1. 判準的數學（⛔ 不是判斷，是可引用的代數）

`blendModeFor("modulate") → ParticleSystem.BLENDMODE_MULTIPLY`
（`apps/client/src/vfx/particleFactory.ts:179`）在 Babylon 7.54.3 走**兩段**，⛔ 不是一段：

| 段 | 出處（逐檔可查） | 做什麼 |
|---|---|---|
| ① shader | `Shaders/particles.fragment.js` 的 `#ifdef BLENDMULTIPLYMODE`（`thinParticleSystem.js:1374` 只在 `BLENDMODE_MULTIPLY` 時 push 這個 define） | `src.rgb = (tex.rgb·col.rgb)·a + 1·(1−a)`，`a = tex.a·col.a` |
| ② blend | `_render()` `engine.setAlphaMode(4)` → `Engines/Extensions/engine.alpha.js` case 4 = `(DST_COLOR, ZERO)` | `out = src.rgb · dst.rgb` |

```
out = dst · [ 1 − a·(1 − tex.rgb·col.rgb) ]        令 δ = a·(1 − tex.rgb·col.rgb)
|out − dst| = dst·δ ≤ δ
```

⭐ **δ < 1/255 ⇒ 8-bit 幀緩衝上每個像素都四捨五入回原值** ——
這就是「畫不出一個像素」的算術定義，⛔ 不是「比較淡」。

### ⛔ 票的前提有兩個，兩個都不成立

| 票 / `PRE2_temp_20260826-0000.md` §2.2 說 | 實際 |
|---|---|
| `MULTIPLY = (DST_COLOR, ONE_MINUS_SRC_ALPHA)` | ⛔ 是 `(DST_COLOR, ZERO)`，而且 shader 先做了一次 premultiply-toward-white |
| `tex.rgb ≈ tex.a`（⇒ 白色 doc 顏色就恆等） | ⛔ 實測 `tex.rgb / tex.a` **中位數 1.273**（`smoke_09` / `light_03` 同值） |

⇒ ⭐ **`col.rgb` 是白色**不足以恆等，**貼圖自己也要是白的**。
⇒ 判準只能從貼圖的實際像素算，⛔ 不可以退化成 `min(R,G,B) ≥ 0.98` 這種只看文件的形狀。

## 3. 落地了什麼

### 3.1 判準⑤（`packages/shared/src/content/vfxDocsBirthVisibility.test.ts`）

- `TexStats` = 每張貼圖 **256×3** 個數（`maxAlphaAtLevel[ch][L]` = 該通道值為 L 的 texel 裡最大的 alpha）。
  ⭐ δ 對固定 col 是 **a 遞增、L 遞減** ⇒ 這 768 個數**精確**復原 max δ，⛔ 不是抽樣。
- `decodePng()`：8-bit / 非交錯 / ct 0·2·3·4·6（出貨 98 張粒子貼圖**全部**是 ct=3 8bit + tRNS）。
- **fail-loud**：modulate 文件的貼圖讀不到 ⇒ 語料測試**紅**並指名它
  （⛔ 「瞎了」與「過了」在此之前長得一樣）。

**兩層量尺自驗**（⛔ 不是一次性手動突變，照這個檔既有的做法）：

| 層 | 斷言 |
|---|---|
| 判準層 | 自造全白貼圖 → **抓得到**；同一張白貼圖但 doc 顏色有色 → **⛔ 不可以被抓**；出貨真貼圖 `smoke_09` → δ > 1/255 且**⛔ 不被抓** |
| ⭐ 解碼器層 | 自造一張 4×5 調色盤 PNG，**五列各用一種濾波器**（None/Sub/Up/Avg/Paeth）→ 逐位元組還原。⚠️ 這一層是必要的：解碼器壞掉時 δ 只會變成**另一個看起來合理的數字**，判準層那三條照樣綠 |

⭐ **獨立交叉驗過**：TS 解碼路徑算出的 δ 與 Python/PIL 逐份相同
（0.1892 / 0.1729 / 0.7359），⇒ 解碼器不是「自己跟自己對答案」。

**現況：5 tests passed；出貨語料 0 份被判準⑤ 抓到，0 份「瞎」。**
`npx tsc --noEmit -p packages/shared/tsconfig.json` **EXIT=0**。

### 3.2 `tools/w3x-import/extract_particles.py`（**註解 only，⛔ 輸出位元組不變**）

在 `luma_key_alpha()` 之後補一段：出貨側 modulate 的**完整兩段合成式** + 為什麼白色 doc 顏色

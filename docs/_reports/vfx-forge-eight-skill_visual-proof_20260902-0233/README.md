## 本輪確認的 main 接縫

1. `godie-e00r` 目前正式 champion 文件仍指向 `champ.skin.rogue`，因此驗收畫面的「初號機」是泛用方塊模型。Editor 必須忠實顯示正式資料，不能私下改成另一個 GLB；main 應修正 authoritative champion/model 映射後再重驗。
2. 八個 fixture 永久只做 Editor capability 驗收；伺服器 proposal 會標記 `editor-capability-fixture` 並拒絕 Promote。
3. AI 對技能機制、動畫或 VFX 的修改必須先進後台單頁審查。自動畫面衛生分數只供排序，人工分數與理由才可形成 verdict。
4. 有正式 script 的技能取代預設 VFX 綁定，不得疊播；傷害、次數與時序仍由 ability JSON 決定。

### ⛔ 唯一的例外，而且它是一個**既有缺陷**

`godie-e00l.e` / `godie-e002.e`（20-03）的 `spawnModelFx` 節點**多掛了一組**：

```json
"onTouch": [{ "kind": "damage", "damageType": "magic", "amount": { "damageTier": "小" } }]
```

**兩個問題，⛔ 是兩件事：**

1. **改成 static 之後它會塌掉。**
   `modelFxInstances` 的 static 分支回 `{ travel: 0 }` 且 **`dir` 是 `undefined`**
   （`sim/effects/spawnModelFx.ts:157-176`）⇒ 下游 `DelayedWave` **不會帶 `advance`**
   （同檔 339 行是 `...(i.dir !== undefined ? { advance: … } : {})`）
   ⇒ 那組傷害從「沿線 14 格掃過」**塌成施法者腳下半徑 1.5 的一圈**，只打得到貼身的人。
2. ⭐ **它在 JASS 裡根本沒有對應物。**
   `A0D5` 的傷害**只有**那個 6×200 極座標迴圈（32333–32343，＝ GGD 的 `damageLine`），
   一次結算。⇒ 這組 `onTouch` 是重製時加上去的**第二份傷害**，
   而 20-03 已經有一條 length 14 的 `damageLine` 蓋住同一條線。

⇒ ⭐ **要分開裁決，⛔ 不要藉演出改動順手把它砍了**（第一守則：出貨數值的每一次改動
要引用得到 owner 的一句原話；他這次說的是**演出**）：

| | 是什麼 | 誰決定 |
|---|---|---|
| **A. 演出改 `static`** | owner 2026-08-24 逐字說了 | ⭐ 可以做 |
| **B. 20-03 那組 `onTouch` 刪不刪** | **傷害**，而且是重製時加的重複計數 | ⛔ **要 owner 勾**（建議：刪，理由是 `damageLine` 已經蓋住同一條線且原作只結算一次） |

⚠️ 如果 A 做了而 B 沒決定，20-03 的實際傷害**會變小**（那組 onTouch 從 14 格塌成 1.5 半徑）
—— ⇒ **A 與 B 要同一批處理**，⛔ 不可以只做 A 就出貨。

## ⑦ 有沒有東西會壞

| 風險 | 判斷 |
|---|---|
| **① preset 無條件注入** | ⚠️ `modelFxPreset.ts::fillOne` 對 `PRESET_FIELDS` 是**無條件**補（只看節點有沒有寫）。而 Zod 的 static refine（`spawnModelFx.ts:240-256` 禁填 `speed`/`distance`）判的是**磁碟上的原始值** ⇒ 模板若留著那兩格 params，注入之後 sim 會拿到兩個沒人讀的數字，⛔ **而且不會有任何東西紅**。⇒ 所以建議 #3（從模板 params 拿掉）是**必要的**，⛔ 不是順手整理 |
| **② 客戶端數學** | ⭐ 零風險。static 走的是 orbit 的「不動」分支（`dx=dz=0`），`modelFxPoseFromWire` 照畫（檔頭逐字） |
| **③ `speed`／`lifeSec` 在 sim** | 已處理：`speed = e.path === "static" ? 0 : …`（`sim/effects/spawnModelFx.ts:245`）、fail-loud 的三格檢查也對 static 放行 `speed`（236 行） |
| **④ `onArrive`** | ⚠️ 四支都有 `onArrive`（爆炸 VFX ＋ 20-03 的 `screenShake`）。static 之下 `ticks = lifeTicks` ⇒ **落點特效延到 2 秒後、在施法者腳下觸發**，⛔ 不再是 14 格外。⭐ 這與原作一致（原作的爆炸 VFX 也在 dummy 那個定點：A0D5 32318-32320 兩發 `AddSpecialEffectLocBJ(LocPoint3, …)`），但**畫面觀感會變**，值得回報時點名 |
| **⑤ ⛔ 這一族目前一個像素都沒畫出來** | `netherstrike.glb` 五個 primitive 全帶 `baseColorFactor:[0,0,0,0]` ＋ `alphaMode:"BLEND"`，而戰鬥場景沒有 GlowLayer／bloom（模板檔頭已記錄）。⇒ ⭐ **改成 static 之後畫面上仍然什麼都看不到**，直到重烘／客戶端走 ALPHA_ADD 修掉。⚠️ **驗收⛔不可以用「看得到就對了」** —— 要驗的是事件 payload 的 `travel:0`／`dir` 缺席 |

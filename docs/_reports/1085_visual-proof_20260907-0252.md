## 看到什麼（A 護盾在）

| 量的東西 | 斷言 | 為什麼它是「看得見」 |
|---|---|---|
| 那兩個字 | 存在一個**葉節點**（`children.length === 0`）其 `textContent === "免疫"` | ⚠️ 第一版只比 `textContent` ⇒ 抓到的是**容器**（它只有一個孩子，字串相等）⇒ `display` 是 `''` 而紅。⭐ 那次紅是對的：一把會抓到容器的尺，量的不是那顆真的節點 |
| 沒被藏 | `style.display === "block"` | 節點在但被藏起來 ＝ 零像素（天譴那次的形狀） |
| alpha | `Number(style.opacity) > 0` | 淡入沒跑完 / 被 HUD 遮罩壓成 0 ＝ 看不見。⚠️ 台子把 `performance.now()` 換成可控時鐘並推進 120ms，否則 `combatTextAlpha(t≈0)` 就是 **0** —— ⭐ 一把不推時鐘的尺會在功能完全正常時量到「看不見」 |
| 字級 | `parseFloat(style.fontSize) > 0` | 字級 0 ＝ 讀不出來 |
| 顏色 | `style.color` 以 `#` 或 `rgb` 開頭 | 透明字 ＝ 只剩描邊，⭐ 那正是 owner 抱怨過兩次的「傷害數字看起來是黑色」（`combatText.ts:1533` 的判例） |
| 位置 | `style.transform` 含 `translate(<px>, <px>)` | 沒有投影 ＝ 畫在 (0,0) 或畫在畫面外 |

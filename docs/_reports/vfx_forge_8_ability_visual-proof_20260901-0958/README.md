## 這次由視覺驗收抓到、並轉成程式守衛的問題

1. `strike` 事件原本沒有從施法者與受害者位置推導方向；帶 `yawFrom:"aim"` 的終結砲因此會退回世界固定方向。播放器現在建立單位方向向量，測試以「目標在 +z，前向位移不可跑到 +x」鎖住。
2. 新增 `modelFx` 時，未處理的黑色 tint 會讓角色實際隱形。本批內容明確使用白色 identity tint；畫面驗收同時確認模型真的出現在連段中。
3. Editor 若默默從 5174 改跑 5175，UI 看似可編輯但所有儲存都會被 Origin 安全閘拒絕。Vite 現在不再靜默換埠；刻意自訂埠時，由 `GGD_EDITOR_ORIGINS` 將實際 loopback origin 傳給 content-api，非 loopback 仍直接拒絕。
4. 貼圖是否有底色不能只看原圖。素材仍先走建置期幾何／材質檢查，再由上述完整技能時間軸以實際 blend mode 做 GPU 逐格檢查。

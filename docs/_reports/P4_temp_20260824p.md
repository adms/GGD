## ⚠️ 這批漏票的**結構性根因**（⛔ 不是誰粗心）

| | |
|---|---|
| 現象 | 11 條裡 **9 條有 commit** —— 工作做了，票沒開 |
| 機制 | commit 訊息的 `(#xxx)` 有兩種東西長得一樣：**GitHub issue** 與 **lane 代號**（`#A1` `#A5` `#E4` `L10` `A2` `A3` `#F2` `#D10` `#D4` `#D5`） |
| 後果 | lane 代號的那些**在 GitHub 上不存在**；而掛錯 issue 的那些，票的**標題**與那件事無關 ⇒ 之後 grep 標題永遠找不到 |
| ⭐ 可以當場檢查的閘 | commit 訊息裡的 `(#\d+)` 必須**真的是一張 issue**，且該 issue 的 body 要提到這次改動的關鍵詞；lane 代號一律寫成 `(lane:A5)` ⇒ ⛔ 不要跟票號同形 |

⇒ 這是下一次「他說了但沒有票」的**同一個根因**，建議一併立一條閘。

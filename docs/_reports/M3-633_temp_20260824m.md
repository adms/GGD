# M3 · GH#633 — Go 的 AttrDefaults 是舊值

## 量到的（⛔ 不是推測）

`apps/platform/internal/combatenv/combatenv.go` 的 `AttrDefaults` 漂了**兩格**：

| key | Go（舊） | TS `ATTRIBUTE_ENV_DEFAULTS` | 來源 |
|---|---:|---:|---|
| `intToManaRegen` | 0.07 | **0.21** | owner 2026-08-20「智慧影響回魔可以增加更多」GH#446 |
| `intToAbilityPower` | 6.5 | **4** | 2026-08-22 系統倍率折進基礎層那一批 |

## ⭐ 根因不是「忘了同步」—— **對帳早就存在，而它撞死在自己的字面量上**

`keysync_test.go::TestAttributeDefaultsMatchTheSharedSimTable` 從一開始就在做
「Go 的 map ↔ TS 的 literal」逐鍵逐值比對。它**是紅的**，但紅的訊息是：

```
"map[...]" should have 9 item(s), but has 11
expected the nine 三圍/派生 coefficients, parsed 11 from .../combatEnv.ts
```

因為它在比對任何一個**值**之前，先撞死在 `require.Len(t, shared, 9)`。
shared 早就長到 11 格（`strToCritChance` / `agiToEvasion` 加進來），
⇒ 這條守衛從那一刻起**再也沒有機會看到值**，而報的是與缺陷無關的計數錯誤
（第二守則失敗形態④：斷言方向跟缺陷無關）。

⭐ 那個字面 `9` 就是這張表的**第四個住處**（第〇·四守則），而它跟每一份抄寫一樣過期了。

## 做了三件事

### ① 值對回 TS（`combatenv.go`）
`intToManaRegen` 0.07→0.21、`intToAbilityPower` 6.5→4。
⛔ 這**不是**新增第四個住處：這份 map 是**刻意的鏡像**（sim fallback，
給「內容樹讀不到」時用），它與 `content/config/combat-env.json` **本來就該不同**
（content 覆寫：`strToAttackDamage` 0.4→0.24、`agiToArmor` 0.15→0.3）。

### ② 拆掉 `require.Len(shared, 9)`（`keysync_test.go`）
換成 `require.NotEmpty` —— 解析空了 `assert.Equal` 會**指名缺哪幾個鍵**，
那才是讀的人要的訊息。⛔ 任何寫死的計數在這裡都只是負債。

### ③ ⭐ 新增一條**配對式**守衛 `TestContentConfigCoversEveryAttributeCoefficient`
斷言 `content/config/combat-env.json` 對**每一個** 三圍係數都有一筆 ——
⛔ 不比對值（值本來就該不同），只比對**關係**。

> 為什麼這條才是這題的結構解：`Service.baseDoc()` = `DefaultFor`（編譯進去的）
> 疊上 `loadContentDefaults`（讀 content）。只要 content 對每一格都有意見，
> **編譯進去的數字就永遠到不了後台**。content 少一格的那一刻，
> `Replace` 的 complete-desired-state 語意（省略的鍵回退到 base）
> 就會把 owner 的值還原成編譯值 —— 那正是 0.07 / 6.5 會出現在「回到預設」的路徑。

## 為什麼**推導不了**（owner 要的那半，逐條）

| 方案 | 為什麼不行 |
|---|---|
| Go 執行期讀 `packages/shared/src/sim/combatEnv.ts` | 出貨的是 Docker 映像，裡面**沒有 packages/shared**（只有 `content/` 是 bind-mount） |
| `//go:embed` 那份 TS/JSON | `go:embed` **不能跨出 package 目錄**（禁 `..`），要嘛複製一份檔案（＝同一個病） |
| 直接讓 `AttrDefaults` = 讀 `content/config/combat-env.json` | ⛔ **語意不同**：這份是「內容樹讀不到時的保險絲」，content 是**覆寫層**。合併兩者＝保險絲跟著平衡改動走，就不是保險絲了 |
| `go:generate` 產一份 `attrdefaults_gen.go` | 產生器**同樣不在任何閘裡**，只是把「會過期的抄寫」換成「會過期的產物」，機械更多、保證不變 |

⇒ **對帳測試是這題唯一真正的閘**：它在測試時讀**真的**來源檔，並**指名**漂掉的那一格。

## ⚠️ 給主 session 的一件事：`go test` 不在出貨閘裡

- `pnpm ship:check`（`tools/parallel-gates/ship.mjs`）只跑 **vitest suites**，⛔ 不跑 `go test`。
- `tools/testrunner/suites.yaml` 有 `platform-go`（`go test ./...`，`enabled: true`），
  但那是**另一支 runner**，不在 `ship:check` 的路徑上。
- ⇒ 這條紅了幾天，**沒有任何人看得見**。要不要把 `platform-go` 接進 `ship:check`
  是主 session 的決定（我沒有動 `tools/`，那在柵欄外）。

# 阿薩謝爾正式配方與反轉試玩

實作提交：`c418923c0ad13e3a2ac62dda1862ac6e61ae996a`。

本批把 32 號阿薩謝爾原稿接成可編譯、可微調、可在 Editor 試玩的六槽配方。所有原始 `sourceDesign`、名字、描述、模型來源與替代標記保持相同；不宣告 37 名或阿薩謝爾原設計已全部完成。

## 實作

- 通用「自訂效果序列」與「自訂事件被動」模板沿用正式 effect／hook schema，可在現有表單編輯巢狀分支。未放寬英雄身分或未使用參數的依賴檢查。
- P 用 `oncePerCast` 集三層負面能量；Q 小擊退；W 固定落點三波且每波重查敵人；E 改成一次近身普攻防守反擊；R 在 0.8 秒釋放時支付最大生命 3%、至少保留 1 HP，以投射物附加自己來源的四秒詛咒。
- EX 先支付三層；目標有自己的 R 詛咒時只移除該詛咒、改給兩秒 AD/AP +10%，不附加一般 EX 傷害。其他來源、已淨化或到期詛咒不觸發反轉。
- 單槽可勾選補足已安裝資源，也可關閉測試不足；不建立不存在的標記或提高容量。整套模擬仍需自行集氣。
- 試玩增加可選 Q/W/E/R 前置施法及等待秒數，經真實 IntentFrame 執行並保留生命、魔力、位置與狀態。可以先 R 再 EX；不捏造詛咒，也不清除冷卻。這些設定不保存到英雄原稿或投稿包。
- 畫面驗收發現 Editor 沒有消費正式 VfxSystem 的浮字池。現在用原 CameraRig 投影，顏色、抬升、漂移、錯開、透明度與壽命讀原池，不再漏掉反转／驚愕文字。

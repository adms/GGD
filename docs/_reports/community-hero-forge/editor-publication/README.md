# 37 名英雄編輯器投稿與發布驗收

當前進度：18/37 名已有當前服務建包與投稿紀錄（含退回待修訂），16/37 名發布至 127.0.0.1 隔離驗收平台。尚未部署正式站。

本輪以使用者最新指示為準：用既有編輯器、模板與微調完成英雄，經預覽、投稿及審查上線。審查逐槽明列接受的 GGD 改編差異；保留角色原名、完整原文及素材來源，不將替代模型或模板稱為原作還原。阿薩謝爾的同來源重複詛咒反轉增益仍保留，未恢復舊交接的替代 EX。

已發布的 16 名英雄曾經固定候選六槽播放與主要施法者／目標模型檢查；後續發現武藤遊戲的召喚依賴未納入舊快照，因此這名的完整視覺驗收須重做，不能將 16 個發布狀態都視為完整驗收合格。小視窗曾有模型可見性警告；全螢幕確認雙方模型與材質正常，沒有修改檢查門檻。武藤遊戲至卡比前六名已另從作者的發布清單確認可見（published-discovery-current.txt）。各版本的審查意見包含六槽 currentBehavior 與 requiredRefinement 的接受差異。

赫蘿建包前及魯路修發布前曾遇既有登入逾期；重新登入原有 model-author／model-reviewer 後完成原作品流程。魯路修失敗紀錄保存在 10/publication-auth-expired.json，正式發布紀錄為同資料夾 publication.json，沒有新增帳號或修改權限。

比利海靈頓的原交接 Q／W／E 與 Owner 原文配錯，已走正式退回流程，再以編輯器「進階編輯」重用既有模板修正為 Q 抓投、W 三秒護盾、E 直線位移後落點打擊。第 11 版重新建包與投稿；ZIP 中 compiled effects 核對一致，sourceDesign、brief、presentation 逐欄相同，原第 4 版候選與 ZIP 保留。仍未實作氣勢、專屬配對動作、首敵停止，審查說明明列接受差異；E 的實際结算是 onLand，不稱沿路接觸命中。證據位於 15/before-refinement.json、after-refinement.json、return-review.json、refined-package-proof.json、review-adaptation.json。最初 UI 讀取器回傳 DOM 造成序列化失敗，改為布林檢查後完成，沒有修改遊戲程式。

固定審查又確認比利第 11 版 W 護盾特效仍在 target，已再次正式退回，並在編輯器將 castEffect 掛點改為 self。第 16 版 ZIP 建置與檢查通過，compiled VFX 也確認 self，原文與 uploadedModel 相同；目前只建包，尚未重投或發布。新增證據為 15/return-vfx-review.json、after-vfx-refinement.json、refined-vfx-package-proof.json。

安茲的 W 模擬已有 summonSpawn，但舊固定 ZIP 未包含召喚英雄 thorne，審查畫面因此缺少死亡騎士替身，已正式退回。修正 shared 引用收集，將明確指定的召喚英雄納入既有套件依賴閉包，並排除代表施法者本人的 self 哨兵；不改遊戲召喚機制。相關 heroPackage、refs、templateExpandedRefs 共 19 項檢查通過。再次由編輯器建立第 4 版套件，已包含 authoring/compiled thorne、champ.thorne 模型及模型資產；尚未重新送審或完成新固定預覽。原缺件 ZIP 與補齊 ZIP 分別保存為 17/*-original.zip、*-summon-fixed.zip，核對紀錄為 summon-package-proof.json。

首次引用修改誤將 self 當成實際英雄 ID，造成吉爾伽美什當次發布被 ContentLoader 拒絕；排除 self 並補測後，原操作重試成功。讀取腳本錯過完成狀態而逾時，隨後直接讀取審查頁確認「吉爾伽美什 · 第 4 版 · 已發布」及上線版本 ID；18/publication.json 與 published.png 為確認證據，失敗／逾時讀取紀錄亦保留。這次失敗來自本輪修正的暫時回歸，未造成既有版本被替換成失敗稿。

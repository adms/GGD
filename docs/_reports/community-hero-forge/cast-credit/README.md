# 每次有效施法一次的觸發額度

此批新增可選的 `HookDef.oncePerCast`。它只支援 `onDamageDealt`，需由持有者自己的一次已接受施法，實際扣除其他單位生命；是否限定敵方仍使用既有 `victim` 選項。一次施法的多個目標、直接傷害、投射物、延遲波次、光束碰撞／抵達、連段、閃電、跳躍／衝刺結束與延燒共用同一份額度。

不計自傷、普通攻擊、未帶施法來源的傷害、反彈與反擊／代放衍生傷害。代放的免費、扣魔、扣魔與冷卻三條路都排除；超距離接近後重試仍保留排除標記。護盾全吸收、免疫、條件／機率不通過不消耗額度；成功後重複命中不再擲機率。既有未啟用此欄的觸發器維持原順序與次數。

## 資料與回放

每次接受施法建立世界內遞增的來源編號，由現存的立即／延遲效果共同持有。最近施法表仍每身體最多六槽；沒有逐場無限保留的已完成施法清單。已觸發紀錄屬於該次施法與持有者／來源／hook 索引。

疊層 DoT 保留最多 `maxStacks` 個來源位置；同一次施法佔多層仍只計一次，滿層再上新的來源時取代最舊來源。refresh 改為最新施法的傷害來源，independent 各自保存。多層仍合併成原有的一次傷害結算，未啟用此欄的傷害觸發器不因來源數而倍增。

啟用此功能的世界把來源編號、額度、現存載體關聯及接近代放標記納入 digest。編號以字串編碼，避免既有量化函式對相差 4096 的整數產生相同輸入。digest 讀取不修改追蹤狀態；未啟用的舊世界不增加來源摘要。

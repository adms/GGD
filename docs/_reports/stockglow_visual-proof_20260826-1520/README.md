## 台子的量尺先自證（⛔ 不然結論作廢）
`calibrate()` 對一個**已知亮**的滿版 control 回：**462,441**（BEFORE 那一輪）／
**462,619**（AFTER 那一輪）—— 兩輪差 0.04%。⇒ 這一頁的數字可以拿來比。

## 開關真的可達（rollback 不是紙上的）
同一頁、同一支技能，只換 `?additive=`：

| | 出貨的 7 份發光材質 |
|---|---|
| `additive=0`（舊） | `TeamGlow0:2 mat1:2 mat2:2 mat3:2 mat4:2 mat0:2 mat2:2` |
| `additive=1`（新） | `TeamGlow0:1 mat1:1 mat2:1 mat3:1 mat4:1 mat0:1 mat2:2` |

（Babylon：`1 = ALPHA_ADD`、`2 = ALPHA_COMBINE`。最後那一份 `mat2:2` 的自發光是全黑
＝不透明幾何 ⇒ **刻意不碰**。）

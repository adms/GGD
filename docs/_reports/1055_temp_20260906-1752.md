### 2.2 一個做過又收回的實驗（寫下來免得下一個人再做一次）

想把 `tools/icon-gen/package.json` 改成**零依賴**（`vitest` 靠根目錄 `node_modules/.bin` —— 量過 `pnpm --filter @ggd/icon-gen exec` 的 PATH 真的含根 `.bin`），讓 CI 不必動 lockfile。
⛔ **量到不行**：pnpm 的 frozen 檢查是**雙向**比對 importer 的 specifiers ——
`specifiers in the lockfile ({"vitest":"^2.1.4"}) don't match specs in package.json ({})`。
⇒ package.json 與 lockfile **必須一起動**；主 session 的 `ddcb3c1b8` 正是那一對。實驗已用 Edit 還原，`git diff -- tools/icon-gen/package.json` 為空。
驗證：HEAD 的那一對 `pnpm install --frozen-lockfile --offline --ignore-scripts` → **EXIT 0**。

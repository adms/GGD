這一類最貴，因為它們**全部是綠燈** —— 看起來一切正常，而量的根本不是你以為的那件事。

| 它以為在量 | ⛔ 實際在量 |
|---|---|
| 全部技能的法強節點 | 只有一格 —— 97 個「普攻觸發」裡看得到 **5** 個 |
| 公式跟手填值吻不吻合 | **只檢查上限**，於是「只有六成」這種偏差靜靜地通過 |
| 投稿開關擋不擋得住 | 一條**不存在的網址**（真正的入口在另一個語言寫的服務裡） |
| 技能範圍跟原作差多少 | 接了模板之後，在比**兩種不同的單位** |
| 連擊加成有沒有生效 | **假人的血量上限** —— 三次量測全是同一個數字 |

> 最後一條的意思是：那條檢查「綠」了很久，**只是因為傷害還不夠大**。

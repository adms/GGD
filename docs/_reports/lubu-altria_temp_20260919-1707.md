## 1.5 ⭐ 要補的閘（具體提案）

### 閘：`headFrac` —— 角色的頭佔正規化身高的幾成

```
fullH   = 套用 hiddenPrimitives 之後，全部可見 primitive 的 bbox 高度
headY   = 模型自己宣告的 `Overhead` 掛點 worldY（WC3 慣例：頭頂正上方）
headFrac      = (headY − fullMinY) / fullH
headOnScreenU = headFrac × 1.8      ← ⭐ 這個數字就是「玩家會看到多高的角色」
```

⭐ **為什麼用 `Overhead` 掛點，⛔ 不猜「哪一片是身體」**：
我前兩版量尺各用了一個猜法，**兩版互相矛盾**，證明猜法不可靠 ——
v1「alphaMode 是 OPAQUE/MASK 的才算身體」被 `MDX_FILTER_MODES[0]` 的 alpha 安全政策騙了
（fm=0 的身體會被升級成 BLEND ⇒ `454064` / `491448` 量出假的「身體很矮」）；
v2「面數最多那一片」在 `467258` 上又偏了 11 個百分點。
⭐ 掛點是**模型自己宣告的**，⛔ 不是我推論出來的 —— 而且 `models.py` 已經在
`entry["attach_points"]` 收它了，⛔ 不必新增抽取邏輯。

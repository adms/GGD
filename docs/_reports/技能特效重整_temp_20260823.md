## 9. 量測方法（可重跑，⛔ 唯讀）

```
/private/tmp/.../b4/scan.py     # w3x ⑥⑦ 823 列 × 出貨 421 支的 join
/private/tmp/.../b4/causes.py   # 共同原因分類 + 22 支可動清單
/private/tmp/.../b4/counts.py   # 每一類「擋住幾支」
```

- **join key**：`content/assets/vfx/w3x-ability-provenance.json` 的 `rawcodes`
  （395/421 支有 rawcode，`joinConfidence` **CONFIRMED 352 · AMBIGUOUS 29 · WEAK 14**）
  ↔ `DUMMY_ORB_MAP` 每一列的 `rawcodes`（381/823 列有）。
  ⛔ **沒有用英雄名做主 join** —— 那是模糊比對；英雄名只用來說明「這 266 列屬於誰」。
- **「模型在 repo」的定義**：`content/models/imported.<stem>.json` 真的存在（111 顆），
  ⛔ 不是「`content/vfx/` 有同名的粒子層」——⚠️ 兩者**完全不同**：
  粒子層補得起 ①落點一次性，**補不起** ⑦（那需要一具**有骨架的 mesh**）。
- **上架狀態** = `content/config/roster.json` 的 `retiredChampions` / `hiddenChampions`
  ＋ 英雄卡 `transform.role === "alternate"`，⛔ 不抄任何字面清單。
- 效果節點是**遞迴**收集的（`onArrive` / `onTouch` / `weightedBranch` 底下的也算）。

# K5 #640 選人畫面技能說明滑不下去 — 完整報告（20260824k）

## 量到的根因（⛔ 不是猜的 —— 在 client-playtest lane 真的進了選人畫面量 DOM）

滾輪**沒有**被誰吃掉（`InputCapture` 的 wheel 只掛在比賽 canvas 上；Babylon
`attachControl` 只掛在預覽 canvas 上）。捲動鏈本身也是通的 —— 真正的病是：

> **tab body（技能說明區）在 1280×720 視窗量到 `clientHeight = 27px`**
> （`scrollHeight = 1016`，technically 可捲 —— 但 27px 的縫玩家根本看不到，
> 滾輪指在 3D 台座／身分列上時一動也不動 ⇒ 「滑不下去」）。

組成：卡片 596px = 3D 台座 **300**（flexShrink:0）＋ 身分列 **~200**
（8/13 出身×路線 + 名言區塊讓它長高了）＋ tabs **43** ＋ 剩 **27** 給說明。
`flex:1 minHeight:0` 對這種擠壓毫無抵抗。視窗越矮越慘（越接近 owner 的筆電）。

## 修法：三段讓位（全部住在 `championProfile.ts` 的純函式，ProfileBlock 只 spread）

`profileScrollContract(compact)`（#640）：
1. **說明區地板** `PROFILE_TAB_BODY_MIN_PX = 160` —— 說明永遠有一塊能讀的窗
2. **台座先讓** `flexShrink:1, minHeight: PROFILE_STAGE_MIN_PX = 180` ——
   跟手機版（`champSelectProfileLayout` 縮台座）同一個取捨，桌機改成漸進式
3. **最後整欄捲** root `overflowY:auto` —— 任何視窗高度都困不住說明
   （也讓 #506 手把捲動層找得到真的 overflow box）

compact（手機）三格全空 —— 外層單一捲軸的行為一個位元組都沒動（#107）。

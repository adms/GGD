```
content/vfx/fx.w3x.orb.bloodbreathstream.p00 / p01 / p02      ← 48f487c3
content/vfx/godie-bloodbreathstream-p0 / p1 / p2              ← initial commit 起
```

`color.start = [1,0,0,1]`、`sizeStops` 非零 ⇒ ⛔ 不是必不可見。

**而這條機制吃的就是 vfx 文件：**

```ts
// packages/shared/src/content/schema/effects/spawnVfx.ts:15
vfxId: zRef("vfx", { soft: true }),
```
· `content/vfx/*.json` 的 `schema` = **`vfx@1`** ← 這條路

⇒ 那 6 支今天用**零個新檔**就寫得出來：
`spawnVfx { at:"bone", attach:"chest", vfxId:"fx.w3x.orb.bloodbreathstream.p00" }`

### ⭐ 根因（可以寫進守則的那一半）

⚠️ 這不是「有人記錯」。它是一個**跨集合的名字巧合**：
同一顆原作 mdx 在 GGD 有**兩種合法表達**（`vfx@1` 粒子 / `model@1` 幾何），
而票文寫下的是**其中一種的路徑**，⛔ 沒有寫「為什麼是這一種」。
⇒ 之後每一輪都 `ls content/models/` ⇒ 沒有 ⇒ 「前置未備」⇒ 複述。
⭐ **沒有任何一輪去問「這條機制吃的是哪一個集合」** —— 而那是 schema 裡的一行。

⭐ 判準（當場可檢查）：**票文寫下一個「缺席的檔案路徑」時，要同時寫下「哪一行程式會去讀它」。**

# 本輪交付狀態

## 2026-09-09：教師配對程式與長度預檢已實跑

[配對與 CPU 預檢報告](DISTILLATION_DATA_PREFLIGHT.md)：固定版本保留 71 筆 shipping 紀錄＋37 名社群成品，共 756 個完整英雄／單槽候選；獨立需求配對並排除三筆確認衝突後，剩 49 個完整英雄＋309 個單槽配對候選，**不是 358 筆已通過機制驗收的訓練資料**。12 項 Node＋4 項 Python 測試通過，576 個輸入 pin／4 個輸出序列化重建相符。

完整英雄本身的序列下限約 3.3k～6.2k tokens；加入整份同版本能力目錄後約 64.8k～67.5k，目錄是主要成本。CPU 量測 57.882 秒，沒有載入模型權重或啟動 GPU。下一步須接精簡索引與按需契約查詢、完整輸出驗證，然後固定正式切分及一輪訓練設定；不截斷六槽、不退回 12 筆 smoke。本輪沒有新造英雄或修遊戲機制，新版訓練尚未開始，目標維持 active。

## 2026-09-09：新版完整英雄生成目標已啟用

使用者已核准 [Codex → 12B 完整可上場英雄目標](CODEX_DISTILLATION_GOAL_20260909.md)，清除舊目標後，系統已成功建立 active 新目標。以已採用英雄＋37 名的既有 Codex 成品教完整生成，涵蓋設定、出身／屬性、六槽技能、機制、特效與必要素材綁定；12B＋script 須自動填入、保存、編譯、匯入並完成對局驗證，零人工補填才算一名成功。使用者另給新英雄，由 Codex／未微調 12B／LoRA 同題比較，新批不回灌訓練或調參。

本輪完成目標與文件設定，尚未凍結新版教師樣本淨數／輸出契約／正式訓練設定，未啟動新訓練或新批推論。已核對另有 37 名校正版 555 題來源判讀輔助資料，不把先前 1,275 題候選數當作全庫上限。新英雄名單待使用者提供，準備與候選模型工作不必等待該名單；最終比較不能自行捏造題目。

下列固定範圍稽核與結果保留為歷史，不覆蓋新目標。資料可作教師示範與成品可正式上場是不同門檻；不要求全庫先取得獨立人工 Gold 才訓練，也不以 Codex 生成自動保證正確。新版允許指定已採用教師來源明示重新分配；入訓後舊題只作已見回歸，舊 run、切分與分數不改。上一版分類優先提案已被取代。

## 實際阻礙與重啟条件

1. 獨立最終評估需新的、未在本研究曝光的完整英雄來源。現有 44 名不能重命名後冒充新盲測；新增資料需先固定來源及家族隔離，再做推論。
2. 已確認受影響的配方需 Main 提供或審核合法點位語意，重跑相同正反例。這不代表其餘資料都無法改善，也不代表所有可能組合已被窮舉。
3. 新增詳細診斷的公開披露需明確授權。原研究 PR 已公開；後续材料未透過其他通道繞過被拒絕的公開留言。

腳本可以自動執行實驗及攔錯，不能保證 12B 達到 95%。目前已有來源判讀微調結果，但未證明可達成完整英雄目標；不啟用研究 adapter、不把未達標狀態標為成功。

後續遵守固定資料的模型工作範圍，不再擴充英雄、補造正例或修配方。新資料或機制問題直接隔離並依守則送票；不因等待引擎修復而阻止現有可用資料的有界模型比較。來源判讀的分数與完整英雄生成分開報告。

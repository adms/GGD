# 結論：結構約束有效，但完整英雄機制沒有提高

本次沒有新訓練、沒有擴資料。固定既存基底／原24步 adapter、原四名開發英雄與評分器，不是新盲測。

- 24步 adapter 的純結構 schema 由3/4到4/4；阿薩謝爾不再輸出違反 minItems 的空 missing 分支。這是事後失敗拆分，未改原分數或用來挑模型。
- 兩組可編譯都維持2/4。好運姐仍因 TARGETED_DELIVERY_REQUIRED 被拒；阿薩謝爾轉為 ACTION_DELIVERY，不能說機制修好。
- 李星 EX 少了原文未要求的推人，來源反例0/3到1/3；但另加獨立 damage，落地前就傷害，局部行為7/7到6/7。R補了傷害但仍缺先進身，兩個距離反例仍失敗。
- 同一解碼下，基底／24步 adapter 的上述指標相同。來源判讀微調的收益仍未證明可轉移到完整英雄生成；不據此推論所有12B或所有微調都無效。

不採用這批輸出為成品、不替換或啟用模型。Grammar 可保留作結構工具，不能免除原文、時序、對象及跨技能關係驗證。此次結果不支持盲目追加 step。

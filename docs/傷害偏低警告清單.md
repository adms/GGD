## 這一份在回答什麼

一支技能的**期望輸出**是「每一卡面秒打出去多少傷害」：

```
rate(形狀, 級距) = 傷害級距[同名那一格] × 期望命中人數[形狀] ÷ 冷卻[形狀][級距]
```

錨點是**對角線的起點**「單體・極小」= **41.67 / 卡面秒**，因為傷害五級距表本來就是拿它展開的（`damageTiers.tiersFromAnchor()`）。
⇒ 單體那一列**恆等於**錨點；偏低只可能出現在別的形狀上。

⚠️ **只警告不擋。** owner 說的是「不合理」不是「不准」，刻意的破例要留空間。

## 一 · ⭐ 決策開關（`config.skill-normalize@1`）

owner 2026-08-21：「決策點一律做成**後台開關**，預設 = 你的建議」。
⭐ 下表的說明是從 **Zod `.describe()` 現讀**的（後台那一頁讀同一份字），⛔ 不是第二份散文。

| 開關 | 現值 | 它在決定什麼 |
|---|---|---|
| `enabled` | `true` | 關掉之後整條正規化規則不跑（閘不叫、報告不產）——一鍵 rollback。⚠️ 關掉不會改變任何技能的行為。 |
| `carrierBaseMax` | `1` | **載體節點**的門檻：小於等於它的傷害葉不算傷害。一顆 `damageArea{amount:{flat:1}, onHitTargets:[…]}` 的工作是送狀態，那 1 點只是為了讓圈成立 —— 收進級距會讓一支純控場技變成 600 傷害的核彈（實測命中 70-03／79-01／92-04／45-002）。填 0 = 載體節點全部回來當傷害技。 |
| `damageLeafScope` | `"cast-amount"` | 「傷害葉」算哪些。`cast-amount` = 只有施放路徑上掛在 `amount` 鍵的（＝ tierize.py 的寫入口徑）。⚠️ `all-leaves` 會把 `passive.hooks` 與 `dot.amountPerTick` 也收進級距 —— 級距是**取代**基礎值的，92-02 消化液每跳 20→600 是 **12 倍**。⛔ 那是平衡改動不是正規化。 |
| `damageColumnBasis` | `"leaf"` | 傷害欄用哪個口徑對「已填的級別」。`leaf` = 對它自己那一葉。⚠️ `total`（owner 裁決 A 的總計）拿來對 `amount.damageTier` 會把 34-04 蒼龍破的**每一段**推到極大（12×6000），一次 4 倍的買 —— 裁決 A 的總計改為驅動**相稱性**，那才是它要回答的問題。 |
| `radiusColumnBasis` | `"authored-node"` | 範圍欄用哪個節點。`authored-node` = 填了級別的那一顆。⚠️ `max-coverage` 會把 13-04 龍星群的散佈半徑 8 對到**每一發**的圈（現在是 3），一次 2.7 倍的買。 |
| `snapPolicy` | `"nearest"` | 自由數字往哪一格收。`nearest` 最忠實，⛔ 不夾帶一次無聲的平衡改動；owner 抱怨「普遍超遠／超大」時要的是 `down`。 |
| `riskAllowance` | `true` | 有**條件上檔**的技能允不允許超出級距上限。owner 2026-08-21 對 65-04 天譴：「他要有**足夠多敵人在範圍內**才有連鎖加成效果，算是有**額外條件風險**」⛔ 不調數值。⭐ 判準從結構推導（ceiling > guaranteed 且有風險因子），⛔ 不是一張豁免名單 —— 12 段打同一目標的蒼龍破沒有上檔，它照全額被管。 |
| `proportionalityExemptNoDamage` | `true` | 沒有傷害葉的控制／位移技要不要豁免相稱性。相稱性規則的分母是**傷害**，一支不造成傷害的定身技拿去對它得到的是一句必然為假的宣稱。⭐ 理由是推導的（效果樹上一片傷害葉都沒有）。 |
| `gapAlert` | `0.25` | 離最近一級多遠才叫「收進去會改變手感」（相對級距值）。⭐ 與 `pnpm tiers:build` 同一個數字，⛔ 不另立一個。 |

### ⭐ 這八招是**一張需求表**，⛔ 不是八個任務

逐招做是 8 輪；⭐ **盤點之後只有五種形狀**（第〇·五守則）：

| 形狀 | 幾招要它 | 引擎今天有嗎 |
|---|---:|---|
| **橫向氣功砲**（長光束、可上色） | 3·5·6·8 = **4 招** | ⭐ 有（`scaleAxis` 非等向縮放，2026-08-26 落地） |
| **dash 斬擊** | 2·4·8 = **3 招** | ⭐ 有（`blink` / `leap` ＋ `damageLine`） |
| **投射後定距爆炸** | 1 | ⭐ 有（`spawnProjectile` ＋ `onHit`） |
| **動畫斬擊**（多段連刀） | 3·4·7 = **3 招** | ⭐ 有（`comboStrikes`，⭐ 段數上限今天從 32 放寬到 **1000**） |
| **反擊起手** | 7 | ⭐ 有（`anim.on = reflectSuccess`，機制四段接縫全通，⭐ **第一份內容刻意留給你**） |

⇒ ⭐ **五種形狀全部做得出來** —— ⛔ 引擎不缺東西，缺的是**編輯器讓人組得出來**。

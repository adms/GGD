## 與 MVP 的分界

MVP 仍須有真正可操作的創作、修改、保存重開、投稿、管理員審查與上架流程。基本所有權、防覆寫、審查綁版及獨立版本回退也不能延後；若它們已實際失效並阻止 MVP，現在就屬重大故障。

此處延後的是完整異常情境、產品操作完善與桌面發行證據，不是允許 MVP 遺失資料、越權發布或用手工搬 JSON 代替編輯器。已有能力保留、已有有效驗收沿用；不為分期拆掉產品。

## 執行限制與結束

P2-01 至 P2-05 已全部核准，沿既有程式、模板、版本制度及 PR／開票規則完成。只驗受影響情境，不自行擴成所有角色、平台和網路狀態的組合。

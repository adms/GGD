### 完成條件

1. 兩批共 74 名／444 槽均保留已接受的角色內容，透過現有編輯器自動匯入／生成並完成投稿；創作、修改、保存重開、預覽與續編入口實際可用，不依賴逐名手工修補 JSON 或繞過 UI 的私人流程。AI 關閉時基本流程仍可用。
2. 管理員審查的就是發布版本；通過後，74 名在同一預定上線服務正常上架為正式英雄。基本所有權、防覆寫、下架／回退及既有獨立版本與歷史保留；不能為縮小驗收而放棄這些核心功能。
3. 實際編輯器與遊戲流程可用，角色可選、可進場，技能、機制及特效無阻止使用的重大失效。編譯通過或隔離平台的名單不能單獨當成正常上線證明。

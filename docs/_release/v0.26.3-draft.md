## ⚡ 閃電：一個像素都沒畫出來過（#571）

你說「**還是**沒上線」是對的。我做了一頁 audition（飛鼠先生 ＋ **10 個敵人** ·
真 SimWorld → 出貨的 65-04 天譴 → 真 `chainLightning` → 出貨的 `VfxSystem`），
**讀畫面緩衝的像素**：

| | 場上弧 | 亮像素 | 最大通道 |
|---|---:|---:|---:|
| **出貨的原始碼** | **32** | **0** | 44 ＝ 完全沒有弧的基準線 |
| 拿掉輝光貼圖 | 32 | **8,947** | **255** |

**根因兩段**：① `CreateRibbon` 用**全 (0,0,0) 的退化路徑**建 ⇒ Babylon 推出來的
**UV 全是 (0,0)**，而 `{instance}` 就地更新**不重算 UV**；② 那張 1×32 的漸層同時當
`emissiveTexture` 與 `opacityTexture`，形狀住在 **alpha** 且兩緣是 0 ⇒ 每條弧都取樣在
最外緣 ⇒ **全透明**。

## 🔓 ⚠️ 一件要你現在就知道的：這兩條路**繞過後台登入**（#796）

後台 `/admin/` 打開會要求帳密，⛔ **但 `/__review/**` 與 `/__live/**` 是 nginx
直接服務的，不會**。實測（匿名、無 token）：

| 路徑 | 結果 |
|---|---|
| `GET /__review/features` | 200 · 25 批的標題／票號／rollback 開關名 |
| `GET /__live/sfx-map` | 200 · 私有 repo 的計算視圖 |
| `POST /__review/feature-verdict` | ⚠️ **任何人都寫得進裁決帳本** |
| `POST /__review/frame`（寫材料） | ✅ **403**（材料是 :ro，這一半是關著的） |

⛔ **我沒有直接把它關掉，兩個理由**：
① 你的指令就是「請同步到線上」讓你看得到 —— 掛上你還沒設定的認證＝**沒有交付**
② ⛔ **我不建立帳號或密碼** —— htpasswd 的內容必須由你自己產

⭐ **一個檔就關上三條路**（`/admin/`、`/__review/`、`/__live/` 共用同一份 include）：

```
htpasswd -c ./ggd-admin.htpasswd <你的帳號>          # 在你自己的機器上產
# 再把一份 auth_basic 設定丟進 host 的 /etc/nginx/ggd-admin/
# 範本：nginx/admin/basic-auth.conf.example
```

⚠️ 關上之後 `host-deploy.sh` 那兩條新的後置條件會開始回 401 ⇒ **要同一批改**，
否則每次部署都出現一個誤報的警告，而**被忽略的閘等於沒有閘**。詳情在 **#796**。

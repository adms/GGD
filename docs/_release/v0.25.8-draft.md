## 🧲 「被普攻的時候好像會被角色黏住走不了」

⭐ **量到的根因是 hitstop（命中定格）** —— ⛔ 不是狀態、⛔ 也不是碰撞推擠：

| 假設 | 量到的 |
|---|---|
| 有一個定身狀態 | ⛔ `rooted` 全程 false、`speedMult` 全程 1.00 |
| 碰撞推擠把你推回去 | ⛔ 被 8 人圍住往外走，淨/意圖 = **1.22**（推擠反而幫你走） |
| ⭐ **hitstop** | ✅ 一發 2–8 tick、**每次傷害重新上值 ⇒ 連段** |

100 tick 裡完全動不了的比例：1 個攻擊者 **4%** ／ 攻速 4 的 1 個 **26%** ／
**8 個圍住攻速 2 → 39%** —— 貼身群戰近四成的 tick 方向盤被拔掉。

⭐ 而**客戶端結構上預測不到**（快照沒有 hitstop 位元）⇒ 影子照走、每 50 ms 被拉回
= 你另外抱怨過的「回溯」逐字同一個形狀。

⇒ **挨打方不再凍走路**（出手方照凍、擊退/衝刺覆寫照凍、前搖/施法/收招一格沒動）。
後台一格 `hitstop.holdsVictimWalk` 可一鍵回頭。

### 👁️ 而「特殊狀態頭上要有圖示」—— 真的有一個，而它的位元從沒亮過

## 🖥️ 商店「像錯誤破圖那樣閃爍」

⛔ **我先前兩次的診斷都是錯的**（兩次都在解釋「黑」，而你看到的是破圖）。

⭐ 量到的根因：中場那顆 engine 是 `alpha:true` + `premultipliedAlpha:true`，
而**引擎 fps 上限 60、合成器 120** ⇒ 逐幀取樣 16 次，buffer **完美地一幀有一幀無**：
`alpha=255` ↔ **`alpha=0`**。

⭐ **一個機制解釋三種描述**：
- 「無」那一半透出去是頁面底色 ⇒ **黑**（我在自己機器上看到的）
- 透出去是**半寫入的 premultiplied buffer** ⇒ **破圖**（你看到的）

⇒ ⛔ 不是兩個缺陷，是**同一塊 alpha 合成層的兩種樣子** —— ⭐ 那正是它在我機器上
不重現的原因。修法 `alpha:false`（⛔ 不改任何一個像素，clearColor 的 alpha 本來就是 1）。

⚠️ 順帶排除掉的（都量過**不是**）：`mix-blend-mode`/`mask`/`blur` 疊在 canvas 上
（全部住在 `isolation:isolate` 底下，A/B 量 fps **一毫秒都沒動**）· `backdrop-filter`
（零個相交）· 雙 GPU context 遷移（兩顆 context 都活著）。

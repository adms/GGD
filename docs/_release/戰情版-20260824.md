### ⚡ 閃電：**一個像素都沒畫出來過**（#571，已修 `88acca1a`）

你說「**還是**沒上線」是對的。我做了一頁 `chain-lightning-audition.html`

**讀畫面緩衝的像素**：

| | 場上弧 | 亮像素 | 最大通道 |
|---|---:|---:|---:|
| **出貨的原始碼** | **32** | **0** | 44 ＝ 完全沒有弧的基準線 |
| 拿掉輝光貼圖 | 32 | **8,947** | **255** |

**根因兩段**：① `CreateRibbon` 用**全 (0,0,0) 的退化路徑**建 ⇒ **UV 全是 (0,0)**，

`opacityTexture`，形狀住在 **alpha** 且兩緣是 0 ⇒ 每條弧都取樣在最外緣 ⇒ **全透明**。

⭐ 三條既有守衛全綠，因為它們問「事件有沒有送 / 頂點在不在 / 它抖不抖」——

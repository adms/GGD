## 🧭 誤導源：owner 問「你是被什麼訊息誤導了嗎」的答案

**34 處存量稽核 → 修完 → 再重掃 → 又 53 筆**（TSCAN 29／DSCAN 9／MSCAN 15）。
根因前二名：① 「改 content/ 就跑 content:build」這句話在 repo 裡出現 **310 次**，
而 `content/` 底下 **621 份是產物** ② CLAUDE.md 自己把一個裝著產物的目錄標成「來源」。

**流量已經有閘**：訊息提到產物就必須指名產生器（棘輪只能變短）· guidance 引用的指令必須存在 ·
裁決清單裡不可以有幽靈步驟名。⭐ 閘立起來的**第一天就抓到自己人**（我當天新寫的守衛）。

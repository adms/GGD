## 🧮 #1029 法強乘數三段式（K=400 · p=0.8 · M=40；`rate` 0.005 不動）

法強 ≤ 400 **逐位元等於今天**；之後 `1 + rate × [K + (K/p)((法強/K)^p − 1)]` 邊際遞減（斜率在 K 連續、永不為 0）；乘數 ≤ ×41。六件裝 3503 法強 ×18.5 → **×14.7**，＋千年積木 ×160 → **×41**。
純度：`Math.pow` 被閘擋 ⇒ `x^(a/b)` 走 b 次方根牛頓法（+−×÷ 逐位元可重現），與 Math.pow 誤差 < 1e-9（`apDamageCurve.test.ts`）。後台三格：膝點 K、遞減指數 p（收成 0.05 一格；p=1 且 M=0 ＝ 回到直線）、硬上界 M。

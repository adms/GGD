## 🧪 純 content 改動**跑不到任何 `tools/` 測試**（#810）

`suitesForPaths()` 的 content 分支回 `{ suites: null, extras: [] }` ——
⭐ `suites: null` 是「全**包**」，⛔ 而 `tools/` 走的是 `extras`。

⚠️ 而 **#667 / #668 的觸發改動都只碰 `content/`**
（英雄搬進 `_legacy` · `attach.*` 綁定進 content）
⇒ **抓得到它們的那幾支守衛，在它們壞掉的那一刻結構上跑不到。**

修法是**推導**的：`sync-io.json` 量到「讀 content」的步驟 → `package.json` 的指令文字
→ 它的 `tools/<dir>`。⚠️ 第一版我從 `writes` 推 ⇒ **只抓到 1 支**（多數產生器寫的是
`content/`／`docs/`，自己的目錄根本不在 writes 裡）。

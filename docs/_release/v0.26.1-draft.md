## 🎯 三個機制，一次解 146 支（第〇·五守則：引擎做機制、JSON 做技能）

| 機制 | 解鎖 | 是什麼 |
|---|---|---|
| `spawnModelFx path:"static"` | **60 支** | 原作 238 具 dummy 是**不動的**（定點擺著播動畫），而我們的 path 只有會跑的四種 |
| `spawnVfx at:"bone"` | **43 支** | 285 次原作掛件是「特效掛在**施法者骨頭**上」（hand/chest/weapon）；⛔ 替身骨架沒有那根骨 ⇒ 退回胸口**照畫**並記一次 log |

## 🖼️ 25 份「一個像素都畫不出來」的特效救回來了

出貨的 239 份特效模型裡 **28 份是零像素**。兩個根因，一次轉檔同時修：

| 因 | 形狀 | 支數 |
|---|---|---|
| 加法輝光被**軟刪除** | 轉檔器把「無 alpha 的輝光材質」寫成全透明 ⇒ 逐位元不可見 → 改成 **LUMA-KEY**（黑底透明、亮處發光） | 15 |
| 純發射器模型被匯出成**空殼** | MDX 有 0 個 mesh（全是粒子發射器），匯出器只出 mesh ⇒ 空檔 → 每顆 emitter 烤三片正交輝光面片 | 10 |

**25/25 全部 ≥1 個可畫 primitive、動畫零遺失**（逐份用獨立解析器驗，⛔ 不信轉檔器的自我回報）。
⛔ 剩 3 份救不回：`collision` 那一族的來源 MDX **真的是空的**（0 geoset / 0 emitter / 0 貼圖）——
而它畫不出東西本來就是對的（那是看不見的碰撞輔助模型，出貨內容也沒人指向它）。

### 拆解之後量到的：**八條裡 GGD 早就對了五條**

落差全部集中在三條，而它們是**同一件事的三張臉** —— 「沒有下令的時候，系統會不會替你出手」：
① 站著會自動索敵（`seekRadius` 48 蓋滿競技場）· ② 被打會自動反擊 · ③ S 按了下一 tick 又自己索敵（等於無效）

⇒ ⭐ **整個模型收斂成一個閘**：真人座位只有 `attackMove`／`hold` 這兩種「你說了要打」的指令才進索敵。三條同時解掉。

| | |
|---|---|
| **後台** | 「指令模型：LoL（關掉＝輔助模式）」，出貨**開** |
| **rollback** | 關掉 = 完整回到這一版之前（站著自動索敵、被打自動反擊、卡住自動接敵） |
| **⛔ 不受影響** | bot（走自己的 AI）· 你手選的目標 · 嘲弄 · A/H · 前搖語意 |

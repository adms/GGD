## ⭐⭐ 這三天最重要的一課：光束砲的四段根因

owner 抓到我把已經查清楚的事實又推翻回錯的。逐行複查的結果：

| 段 | 發生了什麼 |

| ① **誤讀** | 把**沿線傷害取樣的迴圈**讀成「視覺由 N 具組成」。真相：每一個光束 dummy 都是 `CreateNUnitsAtLoc(**1**, …)` ＋ `SetUnitScalePercent` 放大 |
| ② **寫進家族預設** | 推測寫成 `tpl-beam-roll.count.default = **6**`（⚠️ 連誤讀的 10 都不是，**零出處**） |

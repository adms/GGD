## ⭐ 一句話結論：根因是**通用退路的音效池裡混了角色專屬語音**

⛔ **不是**「某一支技能的 `sfxKey` 指錯人」——逐列查過 **420** 支技能的 `sfxKey`／覆蓋層，**一列都沒有指到別位英雄**。

出貨的施法音路由（`apps/client/src/audio/combatSfx.ts` 的 `abilityCast` 分支，逐字）：

```
  abilitySfxCueForAbility(abilityId)   ← ability-sfx-cues.json 的 bindings 覆蓋層
?? wc3CastKey(sfxKey)                   ← 技能文件自己的 sfxKey
?? castElementKey(vfxKey)               ← 元素風聲（⚠️ 只認得 fire / ice / lightning）
?? "abilityCast"                        ← ⭐ 通用退路 —— 問題在這一格
```

而 `abilityCast` 在 `audio-map.json` 裡不是一個檔，是一個 **3 個檔的隨機池**，而那三個檔**全部有主人**：

- `moongo.mp3` → **獸矛傳承使 - 蒼月潮**（憑據：JASS godie-hpb1.w → gg_snd_moongo；champion-voices.godie-hpb1.select）
- `moonjump.mp3` → **獸矛傳承使 - 蒼月潮**（憑據：JASS godie-hpb1.e → gg_snd_moonjump；champion-voices.godie-hpb1.select）
- `nocute.mp3` → **傲嬌電氣老鼠 - 皮卡娘 / 北斗之鼠 - 拳四郎 / 北斗神拳掌門人 - 拳四郎**（憑據：JASS godie-o00k.passive → gg_snd_nocute；JASS godie-u00l.r → gg_snd_nocute；JASS godie-umal.r → gg_snd_nocute；champion-voices.godie-o00k.select）

⇒ ⭐ **297 / 420 支技能**（71 位英雄裡的絕大多數）沒有專屬施法音，所以每一次施法都在**隨機播蒼月潮或皮卡娘的聲音**。莉娜因巴斯的六支技能一支 `sfxKey` 都沒有 ⇒ owner 聽到的**逐字就是這個**（「皮卡皮卡」＝ `nocute` 皮卡娘、「男人喊叫聲」＝ `moongo`/`moonjump` 蒼月潮）。

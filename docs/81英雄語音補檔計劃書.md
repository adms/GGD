④ 接線                    ←── champion-voices.json ＋ manifest ＋ 閘

### ⭐⭐ 每一個 mp3 都要驗**兩個軸**

⚠️ 這是踩過的：`say -v Kyoko 貓貓` 渲染成 **0.030 秒靜音**
（`貓` 是繁體專用字形，日文寫 `猫`）。

⇒ ⭐ **只驗長度抓不到「長度正常而整段數位靜音」**：

```bash
ffprobe -v error -show_entries format=duration -of csv=p=0 <f>.mp3
ffmpeg -hide_banner -i <f>.mp3 -af volumedetect -f null - 2>&1 | grep max_volume
```

判準：**長度 ≥ 0.15 s** 且 **max_volume ≥ −60 dB**。

⭐ **量尺自己要先自證兩個方向**（⛔ 不可以省）：
- 已知**靜音**（`anullsrc` 0.5 s）⇒ 要量到 ≈ **−91 dB**
- 已知**有聲**（任一既有 mp3）⇒ 要量到 ≈ **−1.4 dB**

⛔ 量不到 ⇒ **這台量尺的一切結論作廢**。
